Адаптивный дизайн

чтобы сайт работал на телефоне, планшете и мониторе
главная› Web›18
◈ теория

Сайт, который красиво выглядит на большом мониторе, на телефоне часто превращается в кашу. Адаптивный дизайн — это про то, как сделать так, чтобы всё работало на любом размере экрана.

Первое — meta viewport

Без этой строки в <head> телефон подумает, что сайт «широкий», и просто уменьшит его. Всё будет микроскопическим.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Это первое, что нужно добавить. В твоих файлах оно уже есть, потому что шаблон один — но знай, почему.

Media-запросы — основа

Media-запрос говорит: «примени этот CSS только если экран такой-то».

@media (max-width: 768px) {
  .card {
    width: 100%;
  }
}

max-width: 768px — «если ширина окна не больше 768». Внутри — любые стили, которые применятся только тогда.

Mobile-first vs Desktop-first

  • Mobile-first — сначала пишем стили для телефона, потом через min-width добавляем для больших экранов. Современный стандарт.
  • Desktop-first — сначала для десктопа, через max-width правим под мобильные. Старый подход, ещё встречается.

Пример mobile-first:

/* по умолчанию — телефон */
.card { width: 100%; }

/* планшет и больше */
@media (min-width: 600px) {
  .card { width: 50%; }
}

/* десктоп и больше */
@media (min-width: 1024px) {
  .card { width: 33.333%; }
}

Популярные breakpoint'ы

  • 480px — маленькие телефоны;
  • 600px — планшеты в портрете;
  • 768px — планшеты;
  • 1024px — ноутбуки;
  • 1280px+ — большие мониторы.

Это не закон, а ориентир. Всё зависит от контента.

Flexbox и Grid делают большую часть работы сами

Часто media-запросы вообще не нужны, если сразу писать адаптивно:

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 16px;
}

Это уже адаптив без единого @media. Держи этот приём в голове — он спасает кучу времени.

Гибкие картинки

img {
  max-width: 100%;
  height: auto;
  display: block;
}

max-width: 100% — картинка не вылезет за контейнер. height: auto — сохранит пропорции. display: block — уберёт лишний «зазор» снизу, который появляется у inline-картинок.

Относительные единицы

  • rem — от размера шрифта в html (обычно 16px). Хорошо для типографики и отступов;
  • % — от размера родителя. Для ширин;
  • vw / vh — от размера окна. Осторожно: 100vh на телефонах глючит из-за панели браузера. Лучше 100dvh, где поддерживается;
  • clamp(min, ideal, max) — «не меньше, не больше, а в идеале — так». Например, размер шрифта:
h1 {
  font-size: clamp(1.5rem, 4vw, 2.5rem);
}

На телефоне 1.5rem, на мониторе 2.5rem, посередине — плавно. Очень удобно.

Скрывать и показывать

@media (max-width: 768px) {
  .desktop-menu { display: none; }
  .burger-icon { display: block; }
}

Часто на мобильном просто показывают другой интерфейс — и это нормально.

Проверка

В браузере: F12 → Ctrl+Shift+M (или иконка телефона). Включается режим устройства — можно выбрать iPhone, iPad, разные размеры. Лучший способ проверять адаптив.

Что важно запомнить

  • <meta viewport> — обязательно;
  • @media (max-width: N) или min-width;
  • Mobile-first — современный подход;
  • img { max-width: 100%; } — спасение;
  • clamp() — плавные размеры без media;
  • Grid и Flexbox часто делают адаптив без @media.
✦ домашка

Цель: сделать страницу, которая красиво работает и на телефоне, и на мониторе.

  • Создай файл responsive.html + style.css.
  • Убедись, что в <head> есть <meta name="viewport" ...>.
  • Сделай страницу с:
    • шапкой с логотипом и меню из 4 ссылок;
    • секцией с заголовком и абзацем;
    • галереей из 6 карточек.
  • Начни с мобильного: сначала напиши все стили для узкого экрана (одна колонка, шрифт меньше, карточки во всю ширину).
  • Добавь media-запросы:
    • @media (min-width: 600px) — карточки по 2 в ряд;
    • @media (min-width: 1024px) — карточки по 3 в ряд, меню горизонтальное.
  • Добавь img { max-width: 100%; height: auto; display: block; } — глобально для всех картинок.
  • Используй clamp() для размера h1: например, clamp(1.5rem, 4vw, 2.5rem). Убедись, что заголовок плавно меняется.
  • Главное: открой F12 → Ctrl+Shift+M. Прогони страницу через размеры iPhone SE, iPhone 14, iPad, Desktop. Ничего не должно вылезать, ломаться или быть нечитаемым.
  • Бонус: сделай галерею через repeat(auto-fit, minmax(240px, 1fr)) и убери для неё media-запросы. Убедись, что она и так адаптивна. Это твой новый любимый приём.
