Promise: обещания

как работать с результатом, который будет позже
главная› Web›28
◈ теория

Promise (обещание) — это объект, который представляет результат операции, которая ещё не завершилась, но завершится в будущем.

Аналогия: ты заказала пиццу. Курьер сказал: «привезу через 30 минут». Это обещание. Оно ещё не выполнено, но ты знаешь: либо привезут, либо нет. Ты можешь заниматься своими делами, а когда курьер позвонит — отреагировать.

Promise работает так же: функция запускает долгую операцию, сразу возвращает «обещание», а ты можешь «подписаться» — что делать, когда результат придёт.

Три состояния Promise

  • pending — «в процессе». Ещё ничего неизвестно.
  • fulfilled — «выполнено». Всё получилось, есть результат.
  • rejected — «отклонено». Что-то пошло не так, есть ошибка.

Promise может перейти только из pending в fulfilled или rejected — один раз. Назад пути нет.

Создание Promise

const promise = new Promise((resolve, reject) => {
  // тут делаем что-то долгое
  const success = true;
  
  if (success) {
    resolve("всё ок");        // выполнено
  } else {
    reject("что-то сломалось"); // отклонено
  }
});

resolve — вызов, когда всё хорошо. reject — когда ошибка. Обе — функции, которые передаются автоматически.

Как получить результат: .then() и .catch()

promise
  .then(result => {
    console.log("успех:", result);  // "всё ок"
  })
  .catch(error => {
    console.log("ошибка:", error);
  });

.then() — что делать при успехе. .catch() — что делать при ошибке. .finally() — что делать в любом случае (необязательно).

Пример: таймер как Promise

function wait(ms) {
  return new Promise(resolve => {
    setTimeout(() => {
      resolve(`прошло ${ms} миллисекунд`);
    }, ms);
  });
}

wait(2000).then(message => {
  console.log(message);  // "прошло 2000 миллисекунд"
});

Функция wait возвращает Promise. Мы «подписываемся» через .then() — и получаем результат, когда он готов.

Цепочки .then()

Promise можно выстраивать в цепочку. Каждый .then() возвращает новый Promise.

wait(1000)
  .then(() => {
    console.log("шаг 1");
    return wait(1000);
  })
  .then(() => {
    console.log("шаг 2");
    return wait(1000);
  })
  .then(() => {
    console.log("шаг 3 — готово");
  });

Код выполнится по очереди: 1 секунда → «шаг 1», ещё 1 секунда → «шаг 2», ещё 1 секунда → «шаг 3».

Promise.all() и Promise.race()

Promise.all() — ждёт, когда все Promise завершатся, потом отдаёт массив результатов.

Promise.all([wait(1000), wait(2000), wait(1500)])
  .then(results => {
    console.log(results);
    // все три закончились, время — 2 секунды (самый долгий)
  });

Работает параллельно. Если хотя бы один Promise отклонён — all тоже отклоняется.

Promise.race() — отдаёт результат первого завершившегося Promise.

Promise.race([wait(1000), wait(2000)])
  .then(result => {
    console.log(result);  // "прошло 1000 миллисекунд"
  });

Promise в реальной жизни

Самый частый пример — fetch для запросов к серверу. Он возвращает Promise:

fetch("https://api.example.com/data")
  .then(response => response.json())
  .then(data => {
    console.log("данные:", data);
  })
  .catch(error => {
    console.log("ошибка:", error);
  });

Это будет тема 30. Пока просто знай: fetch — это Promise.

Главное правило

Promise — это не сам результат, это обещание результата. Ты не можешь «прочитать» значение Promise сразу. Ты только подписываешься: «когда придёт — сделай вот это».

Главное из темы

  • Promise — объект, представляющий результат будущей операции.
  • Три состояния: pending → fulfilled / rejected.
  • Создаётся через new Promise((resolve, reject) => ...).
  • Результат получается через .then(), ошибка — через .catch().
  • Цепочки .then() выполняются по порядку.
  • Promise.all() — все сразу, Promise.race() — первый завершившийся.
  • fetch возвращает Promise — это основа работы с API.
