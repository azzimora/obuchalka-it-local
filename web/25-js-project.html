Мини-проект на JavaScript

собрать всё вместе: HTML + CSS + JS + localStorage

◈ теория

Это последняя тема курса. Здесь ты соберёшь всё, что выучила: структуру, стили, Flexbox, Grid, анимации, адаптив, JS, DOM, события, localStorage. Один проект, но настоящий.

Задача: сделать одно из трёх приложений на выбор. Не учебное упражнение, а рабочую штуку, которой можно пользоваться.

Что нужно сделать (общее для всех проектов)

  • Структура: папка с index.html, css/style.css, js/script.js;
  • Стиль: тёмная тема или своя, с акцентами. Не «белый фон и чёрный текст»;
  • Адаптив: работает и на телефоне (проверь через F12 → Ctrl+Shift+M);
  • JS: используются события, DOM, localStorage;
  • Мелочи: минимум одна CSS-анимация, hover-эффекты, аккуратные кнопки;
  • Accessibility: labels у полей, достаточно контрастные цвета, кликабельные зоны не меньше 40px;
  • Бэкап: перед сдачей проверь, что данные сохраняются и восстанавливаются после перезагрузки.

Проект 1. Список задач (todo)

Классика, которую должен написать каждый.

  • Поле ввода + кнопка «добавить»;
  • Список задач с чекбоксами «выполнено»;
  • Удаление задачи (клик по корзине или кнопка);
  • Счётчик: «3 из 7 выполнено»;
  • Фильтры: все / активные / выполненные;
  • Все данные — в localStorage;
  • Бонус: редактирование задачи двойным кликом;
  • Бонус: drag-and-drop для порядка.

Что тренируется: массивы, объекты, DOM, события, localStorage.

Проект 2. Трекер привычек

Приложение, где отмечаешь, что сегодня сделала: чтение, спорт, вода, учёба.

  • Список привычек (можно добавлять/удалять);
  • 7 ячеек — дней недели;
  • Клик по ячейке отмечает «сделано»;
  • Прогресс-бар на неделю по каждой привычке;
  • Всё сохраняется в localStorage;
  • Бонус: streak — сколько дней подряд;
  • Бонус: анимация при отметке.

Что тренируется: сложная структура данных, динамическая отрисовка, работа с датами.

Проект 3. Заметки / дневник

Личные записи, которые сохраняются между сессиями.

  • Поле для заголовка, большое поле для текста;
  • Кнопка «сохранить»;
  • Список сохранённых заметок слева или сверху;
  • Клик по заметке открывает её в редакторе;
  • Удаление заметки;
  • Автосохранение при вводе (через input + debounce);
  • Все данные — в localStorage;
  • Бонус: поиск по заметкам;
  • Бонус: дата последнего изменения.

Что тренируется: работа с текстом, debounce, состояние приложения.

Проект 4. Своя идея

Если есть что-то своё — калькулятор калорий, трекер настроения, список фильмов, что угодно. Главное, чтобы выполнялись требования выше.

План работы (важно!)

Не пиши всё сразу. Так делают профессионалы:

  1. Структура. Сначала — HTML без стилей и JS. Просто разметка: где что лежит. Открой в браузере, посмотри, что всё на месте;
  2. Стили. Потом CSS. Тёмная тема, акценты, отступы. Сначала «работает», потом «красиво»;
  3. Данные. Потом — структура данных. Как ты будешь хранить задачи/привычки/заметки? Массив объектов? Один объект с полями?
  4. Функции. Потом — JS. По одной функции за раз: addTask(), renderTasks(), deleteTask(), saveTasks(). Каждую проверяй через console.log;
  5. localStorage. В конце — сохранение и загрузка. Всегда в конце, когда логика уже работает;
  6. Полировка. Анимации, hover, мелочи, адаптив.

Не начинай со стилей. Сначала разметка и логика, потом красота. Это правило, которое экономит часы.

Как дебажить

  • Открой F12 → Console. Если что-то не работает — там красная ошибка. Читай её;
  • Расставь console.log в ключевых местах: что пришло в функцию, что вышло;
  • Открой F12 → Application → Local Storage — увидишь, что сохраняется на самом деле;
  • Если не работает — закомментируй половину кода. Работает? Значит, проблема в другой половине. Так находят баги.

Что важно помнить

  • Сначала HTML, потом CSS, потом JS, потом localStorage;
  • Данные — массив объектов, а не куча переменных;
  • Одна функция — одна задача;
  • console.log — твой друг;
  • localStorage — только строки, объекты через JSON;
  • Проверяй на телефоне через DevTools.

Это финал курса. Дальше — ты сама. Но ты уже знаешь достаточно, чтобы делать настоящие проекты и учиться дальше. И это не «маленькое достижение». Это большое.

✦ домашка

Цель: сделать одно рабочее приложение целиком, от разметки до localStorage.

  • Выбери проект: todo, трекер привычек, заметки — или свою идею.
  • Создай структуру папок: 
    my-project/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
  • Пройди по шагам плана:
    • Шаг 1: HTML без стилей. Открой в браузере, убедись, что всё на месте. Скриншот «до».
    • Шаг 2: CSS. Тёмная тема, акценты, отступы. Скриншот «после».
    • Шаг 3: структура данных. Опиши в комментарии, как хранишь. Например: tasks = [{id, text, done}].
    • Шаг 4: функции JS. По одной. Каждую проверяй через console.log и вручную в консоли.
    • Шаг 5: localStorage — сохранение и загрузка.
    • Шаг 6: анимации, hover, адаптив.
  • Обязательные проверки:
    • Данные сохраняются после перезагрузки;
    • Работает на телефоне (DevTools, iPhone SE);
    • Все кнопки кликабельны и работают;
    • Нет ошибок в консоли (F12 → Console);
    • В localStorage видно твои данные (F12 → Application).
  • Бонус: опубликуй на GitHub Pages или Netlify — получи публичную ссылку. Это уже портфолио.
  • В поле ниже запиши: какой проект выбрала, что получилось, что было сложно, что хотелось бы добавить.

Не торопись. Это финальный проект, на него можно потратить несколько дней. Это нормально. Настоящие проекты не делаются за вечер.
