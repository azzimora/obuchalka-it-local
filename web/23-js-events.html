События

клик, ввод, отправка, наведение — JS реагирует
главная› Web›23
◈ теория

Событие — это то, что происходит на странице: клик, ввод текста, отправка формы, прокрутка, наведение мыши. JS может «слушать» события и реагировать на них. Это то, что делает страницу интерактивной.

addEventListener — основной инструмент

const btn = document.querySelector(".btn");

btn.addEventListener("click", () => {
  console.log("нажали!");
});

Три части: кто слушает, какое событие, что делать.

Главные события

  • click — клик мышью или тапом;
  • input — ввод в поле (срабатывает на каждое изменение);
  • change — значение поля изменилось и потеряло фокус;
  • submit — отправка формы;
  • keydown / keyup — нажатие / отпускание клавиши;
  • mouseenter / mouseleave — мышь вошла / ушла;
  • focus / blur — поле получило / потеряло фокус;
  • scroll — прокрутка.

Объект события

Функция-обработчик получает event — объект с кучей информации о том, что произошло.

btn.addEventListener("click", (event) => {
  console.log(event.target);      // на что кликнули
  console.log(event.clientX);     // координата X мыши
  console.log(event.key);         // для клавиатуры
});

event.target — самый частый: это элемент, на котором произошло событие.

Форма и preventDefault

По умолчанию форма при submit перезагружает страницу. Чтобы этого не было:

const form = document.querySelector("form");

form.addEventListener("submit", (event) => {
  event.preventDefault();   // отменить перезагрузку
  const value = document.querySelector("#name").value;
  console.log("Привет,", value);
});

Запомни preventDefault() — он нужен почти всегда, когда работаешь с формами и ссылками.

Получить значение поля

const input = document.querySelector("#name");
input.addEventListener("input", () => {
  console.log(input.value);
});

.value — текущий текст в поле. Для чекбоксов — .checked (true/false).

Живой пример: счётчик

<button id="plus">+</button>
<span id="count">0</span>

<script>
  let count = 0;
  const btn = document.getElementById("plus");
  const display = document.getElementById("count");

  btn.addEventListener("click", () => {
    count++;
    display.textContent = count;
  });
</script>

Живой пример: живой поиск

<input id="search" placeholder="поиск...">
<ul id="list">
  <li>яблоко</li>
  <li>груша</li>
  <li>слива</li>
</ul>

<script>
  const search = document.getElementById("search");
  const items = document.querySelectorAll("#list li");

  search.addEventListener("input", () => {
    const query = search.value.toLowerCase();
    items.forEach(item => {
      const match = item.textContent.toLowerCase().includes(query);
      item.style.display = match ? "" : "none";
    });
  });
</script>

Это уже настоящий функционал, который используется везде.

Делегирование событий

Если элементов много (например, список), не надо вешать обработчик на каждый. Вешают на родителя и смотрят, куда кликнули:

const list = document.querySelector("#list");
list.addEventListener("click", (event) => {
  if (event.target.tagName === "LI") {
    console.log("кликнули на:", event.target.textContent);
  }
});

Это делегирование — работает даже для элементов, которые добавятся позже.

Что важно запомнить

  • addEventListener("click", fn) — вешать обработчик;
  • event.target — на чём произошло событие;
  • event.preventDefault() — для форм и ссылок;
  • input.value — значение поля;
  • Делегирование — когда элементов много;
  • Скрипт в конце <body>, иначе элементов ещё нет.
✦ домашка

Цель: сделать три интерактивных штуки. Это твои первые настоящие программы.

  • Создай файл events.html + style.css.
  • Мини-проект 1 — счётчик:
    • кнопки «+» и «−»;
    • число между ними;
    • при клике число меняется;
    • бонус: кнопка «сброс» обнуляет.
  • Мини-проект 2 — смена темы:
    • кнопка;
    • при клике на <body> переключается класс dark через classList.toggle;
    • в CSS опиши body.dark { background: #111; color: #eee; };
    • текст кнопки меняется: «тёмная» / «светлая».
  • Мини-проект 3 — живой поиск:
    • поле ввода + список из 6–8 пунктов;
    • при вводе скрывай пункты, которые не подходят;
    • бонус: если ничего не найдено — покажи «ничего не найдено».
  • Главное — кнопка «лайк»: сделай сердечко/кнопку, при клике на которую она меняет цвет и текст (например, «♡ 0» → «♥ 1» → «♥ 2»). Счётчик кликов храни в переменной.
  • Проверка: открой F12 → Console. Если что-то не работает — там будет ошибка красным. Читай её — она подскажет, что не так.
