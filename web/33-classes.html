Классы и ООП

объекты, которые умеют больше
главная› Web›33
◈ теория

В теме 21 мы знакомились с объектами — это «коробки» с данными. Классы — следующий шаг: шаблон, по которому создаются объекты одного вида.

Аналогия: класс — это чертёж дома. Объект — построенный по чертежу дом. Один чертёж — много домов.

Зачем нужны классы

Представь, что нужно создать 100 пользователей. Без классов:

const user1 = { name: "Аня", age: 17, greet() { return `привет, я ${this.name}`; } };
const user2 = { name: "Макс", age: 18, greet() { return `привет, я ${this.name}`; } };
// ... и так 100 раз

Много повторений. Если поменять формулу приветствия — придётся править в 100 местах.

С классом:

class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  
  greet() {
    return `привет, я ${this.name}`;
  }
}

const user1 = new User("Аня", 17);
const user2 = new User("Макс", 18);

console.log(user1.greet());  // "привет, я Аня"
console.log(user2.greet());  // "привет, я Макс"

Один шаблон — много объектов. Меняешь в одном месте — меняется везде.

Анатомия класса

class User {
  constructor(name, age) {   // ← вызывается при создании
    this.name = name;        // ← свойства объекта
    this.age = age;
  }
  
  greet() {                  // ← метод
    return `привет, я ${this.name}`;
  }
}

const user = new User("Аня", 17);
  • constructor — специальный метод, который вызывается при создании объекта. Здесь задаются начальные значения.
  • this — ссылка на сам объект. Через this.name класс обращается к своему свойству.
  • new — ключевое слово для создания объекта из класса.
  • методы — функции внутри класса. Вызываются как user.greet().

Методы и свойства

Свойства — данные объекта. Методы — действия объекта.

class Counter {
  constructor() {
    this.count = 0;      // свойство
  }
  
  increment() {          // метод
    this.count++;
  }
  
  decrement() {
    this.count--;
  }
  
  reset() {
    this.count = 0;
  }
}

const c = new Counter();
c.increment();
c.increment();
console.log(c.count);  // 2
c.reset();
console.log(c.count);  // 0

Наследование

Один класс может «наследовать» другой. Дочерний класс получает все свойства и методы родителя, и может добавлять свои.

class Animal {
  constructor(name) {
    this.name = name;
  }
  
  speak() {
    return `${this.name} издаёт звук`;
  }
}

class Dog extends Animal {
  speak() {
    return `${this.name} говорит гав`;
  }
  
  fetch() {
    return `${this.name} приносит мяч`;
  }
}

const dog = new Dog("Бим");
console.log(dog.speak());   // "Бим говорит гав"
console.log(dog.fetch());   // "Бим приносит мяч"

extends — «наследует от». Dog получает всё от Animal и может переопределить методы.

super — вызов родителя

Если в дочернем классе нужен конструктор, надо вызвать super() — конструктор родителя:

class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);           // вызываем родительский конструктор
    this.breed = breed;    // добавляем своё
  }
  
  info() {
    return `${this.name}, порода ${this.breed}`;
  }
}

const dog = new Dog("Бим", "овчарка");
console.log(dog.info());  // "Бим, порода овчарка"

Без super() будет ошибка — JavaScript требует сначала вызвать родителя.

Приватные поля

Иногда нужно, чтобы свойство было доступно только внутри класса. Для этого перед именем ставится #:

class Bank {
  #balance = 0;       // приватное поле
  
  deposit(amount) {
    this.#balance += amount;
  }
  
  getBalance() {
    return this.#balance;
  }
}

const bank = new Bank();
bank.deposit(100);
console.log(bank.getBalance());  // 100
// console.log(bank.#balance);   // ← ошибка, недоступно снаружи

Геттеры и сеттеры

Можно сделать так, чтобы свойство выглядело как поле, но за ним стояла функция:

class Circle {
  constructor(radius) {
    this.radius = radius;
  }
  
  get area() {
    return Math.PI * this.radius ** 2;
  }
  
  set diameter(value) {
    this.radius = value / 2;
  }
}

const c = new Circle(5);
console.log(c.area);      // 78.54 (выглядит как свойство, но это функция)
c.diameter = 10;          // сеттер меняет radius
console.log(c.radius);    // 5

Классы и обычные объекты: что выбрать

  • Обычный объект — когда нужна одна-две структуры. Например, настройки, конфиг.
  • Класс — когда нужно много объектов одного вида. Например, пользователи, товары, карточки, игровые персонажи.
  • Класс с наследованием — когда есть иерархия. Например, животные → собаки, кошки.

Классы в реальной жизни

Классы используются везде:

  • В React компоненты часто пишут классами (раньше — почти всегда);
  • В играх — персонажи, оружие, локации;
  • В приложениях — пользователи, заказы, товары;
  • В библиотеках — для инкапсуляции сложной логики.

Главное из темы

  • Класс — шаблон для создания объектов.
  • constructor задаёт начальные свойства.
  • new ClassName() создаёт объект.
  • this — ссылка на сам объект.
  • extends и super() — для наследования.
  • # перед именем — приватное поле.
  • get / set — свойства-функции.
