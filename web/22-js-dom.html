DOM — работа со страницей

JS находит элементы и меняет их
главная› Web›22
◈ теория

DOM (Document Object Model) — это представление HTML-страницы в виде дерева объектов. Каждый тег — узел, у каждого узла есть свойства и методы. JS может находить узлы и менять их: текст, стили, классы, добавлять и удалять элементы.

До этой темы JS жил сам по себе, в консоли. Теперь он дотягивается до страницы.

Как найти элементы

  • document.getElementById("id") — один элемент по id;
  • document.querySelector("селектор") — первый по CSS-селектору;
  • document.querySelectorAll("селектор") — все (NodeList, можно перебрать);
  • document.getElementsByClassName("...") — по классу (устаревает, лучше querySelector).
const title = document.querySelector("h1");
const buttons = document.querySelectorAll(".btn");
const card = document.getElementById("main-card");

Правило: почти всегда используй querySelector и querySelectorAll — они работают с любыми CSS-селекторами.

Что можно делать с элементом

Менять текст:

title.textContent = "Новый заголовок";

textContent — просто текст, безопасно. innerHTML — с тегами, но опаснее (можно случайно вставить чужой код).

Менять стили:

title.style.color = "pink";
title.style.fontSize = "2rem";

В JS свойства CSS пишутся camelCase: font-size → fontSize, background-color → backgroundColor.

Менять классы:

card.classList.add("active");
card.classList.remove("hidden");
card.classList.toggle("open");   // добавить, если нет; убрать, если есть
card.classList.contains("open"); // true / false

Это самый правильный способ менять внешний вид из JS — стили держи в CSS, а JS только переключает классы.

Читать и менять атрибуты:

const img = document.querySelector("img");
img.src = "new.jpg";
img.alt = "новое описание";
img.setAttribute("data-id", "5");
const id = img.getAttribute("data-id");

Создавать и удалять элементы

// создать
const newLi = document.createElement("li");
newLi.textContent = "новый пункт";

// найти родителя и добавить
const list = document.querySelector("ul");
list.appendChild(newLi);

// удалить
newLi.remove();

Перебор нескольких элементов

const items = document.querySelectorAll(".item");
items.forEach(item => {
  item.textContent = "изменено";
});

querySelectorAll возвращает NodeList, у которого есть forEach — удобно.

Пример: меняем заголовок по клику

(про события — в следующей теме, но вот маленький тизер)

<h1 id="title">Старый заголовок</h1>
<button id="change">поменять</button>

<script>
  const title = document.getElementById("title");
  const btn = document.getElementById("change");
  btn.addEventListener("click", () => {
    title.textContent = "Новый заголовок!";
  });
</script>

Что важно запомнить

  • Скрипт подключается в конце <body>, иначе элементов ещё нет;
  • querySelector — один, querySelectorAll — все;
  • textContent — менять текст, innerHTML — с тегами;
  • classList — менять классы, а не стили напрямую;
  • createElement + appendChild — создавать элементы;
  • .remove() — удалять.

Главное правило: JS не должен знать, как выглядит элемент. Он только добавляет/убирает классы. За внешность отвечает CSS. Так код остаётся чистым.

✦ домашка

Цель: научиться находить элементы и менять их из JS.

  • Создай файл dom.html с обычным каркасом. В HTML сделай:
    • заголовок <h1 id="title">;
    • параграф <p class="text">;
    • три кнопки <button class="btn">;
    • список <ul id="list"> с двумя пунктами.
  • Скрипт — <script> в конце <body>.
  • Упражнение 1 — найти и поменять:
    • найди #title и поменяй текст через textContent;
    • найди .text и поменяй цвет через .style.color;
    • найди все .btn через querySelectorAll и перебери через forEach, каждому поставив текст «Кнопка N».
  • Упражнение 2 — классы: добавь заголовку класс highlight через classList.add. В CSS опиши .highlight { color: pink; } — увидишь, что цвет изменился.
  • Упражнение 3 — создать элемент: через createElement создай новый <li> с текстом «новый пункт» и добавь в #list через appendChild. Обнови страницу — пункт появится.
  • Упражнение 4 — удалить: найди первый <li> и удали через .remove().
  • Упражнение 5 — toggle: сделай кнопку, которая при клике через classList.toggle("active") переключает класс на параграфе. В CSS опиши .active { font-weight: bold; } — увидишь, что при повторном клике жирность снимается.
  • Главное: открой F12 → Console. Напиши document.querySelector("h1").textContent = "Привет из консоли" — заголовок на странице поменяется прямо сейчас, без перезагрузки. Это ощущение «JS дотягивается до страницы» — ключевое.
