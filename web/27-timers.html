setTimeout и setInterval

как заставить код подождать или повторяться
главная› Web›27
◈ теория

В прошлой теме мы говорили об асинхронности. Теперь — про два инструмента, которые с ней работают: setTimeout и setInterval.

setTimeout — «сделай через N миллисекунд»

Выполняет код один раз через указанное время. Миллисекунды — это 1/1000 секунды. То есть 1000 = 1 секунда.

setTimeout(() => {
  console.log("прошло 2 секунды");
}, 2000);

Синтаксис: setTimeout(функция, миллисекунды).

Функцию можно передать двумя способами:

// стрелочная
setTimeout(() => console.log("раз"), 1000);

// обычная именованная
function sayHi() {
  console.log("привет");
}
setTimeout(sayHi, 1000);  // ← без скобок!

Важно: если написать setTimeout(sayHi(), 1000) — функция вызовется сразу, а таймер получит undefined. Нужно передавать имя функции, без скобок.

Отмена таймера: clearTimeout

setTimeout возвращает id таймера — число, по которому его можно отменить.

const id = setTimeout(() => {
  console.log("это не выполнится");
}, 5000);

clearTimeout(id);  // отменили

Полезно, когда пользователь делает что-то, что отменяет предыдущее действие. Например, закрыл окно — таймер не срабатывает.

setInterval — «делай каждые N миллисекунд»

Выполняет код многократно с указанным интервалом.

setInterval(() => {
  console.log("прошло 1 секунда");
}, 1000);

Этот код будет выводить строку каждую секунду, пока страница открыта. Бесконечно.

Использование: часы на странице, обновление данных, анимации, счётчики.

Остановка: clearInterval

У setInterval тоже есть id. Чтобы остановить — clearInterval(id).

let seconds = 0;

const id = setInterval(() => {
  seconds++;
  console.log(seconds);
  
  if (seconds >= 5) {
    clearInterval(id);
    console.log("остановлено");
  }
}, 1000);

Этот код будет считать до 5, потом остановится сам.

Практический пример: счётчик на странице

<div id="timer">0</div>
<button id="stop">стоп</button>

<script>
  let count = 0;
  const timerEl = document.getElementById("timer");
  
  const id = setInterval(() => {
    count++;
    timerEl.textContent = count;
  }, 1000);
  
  document.getElementById("stop").addEventListener("click", () => {
    clearInterval(id);
  });
</script>

На странице появится число, которое увеличивается каждую секунду. Кнопка «стоп» останавливает.

Небольшой трюк: задержка перед действием

Часто setTimeout используется, чтобы «подождать» перед выполнением. Например, показать сообщение и через 3 секунды его спрятать:

function showMessage(text) {
  const msg = document.createElement("div");
  msg.textContent = text;
  msg.className = "toast";
  document.body.appendChild(msg);

  setTimeout(() => {
    msg.remove();
  }, 3000);
}

Debounce — важный приём

Debounce — это когда мы «откладываем» выполнение функции, пока пользователь не перестанет что-то делать. Например, чтобы не искать по каждой букве, а подождать, пока человек допишет слово.

let debounceId;

input.addEventListener("input", () => {
  clearTimeout(debounceId);
  
  debounceId = setTimeout(() => {
    console.log("ищем:", input.value);
  }, 500);
});

Пока пользователь печатает — таймер сбрасывается и запускается заново. Функция выполнится только когда он остановится на 500 мс. Это основа «живого поиска».

Важно помнить

  • setTimeout — один раз через N мс.
  • setInterval — повторяется каждые N мс.
  • Оба возвращают id для отмены: clearTimeout(id) / clearInterval(id).
  • Функцию передавать без скобок: setTimeout(fn, 1000), а не setTimeout(fn(), 1000).
  • Время в миллисекундах: 1000 = 1 секунда.
  • Таймеры не блокируют код — это асинхронные операции.
