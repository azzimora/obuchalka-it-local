Хранение данных в браузере

localStorage — чтобы данные не терялись после перезагрузки
главная› Web›24
◈ теория

Всё, что JS хранит в переменных, пропадает при перезагрузке страницы. let count = 5; — и после F5 снова 0. Чтобы данные жили между сессиями, используют localStorage.

Что это

Встроенное в браузер хранилище. Работает как мини-база данных прямо в браузере: данные остаются, даже если закрыть вкладку или выключить компьютер. Хранится отдельно для каждого сайта (в твоём случае — для каждого файла-страницы).

Четыре операции

// сохранить
localStorage.setItem("name", "Аня");

// прочитать
const name = localStorage.getItem("name"); // "Аня"

// удалить одно
localStorage.removeItem("name");

// очистить всё
localStorage.clear();

Всё. Больше ничего не нужно. Это очень простой API.

Важно: только строки

localStorage хранит только строки. Число 5 превратится в "5". Для объектов и массивов — JSON:

const user = { name: "Аня", age: 17 };

// сохранить объект
localStorage.setItem("user", JSON.stringify(user));

// прочитать объект
const saved = JSON.parse(localStorage.getItem("user"));
console.log(saved.name); // "Аня"

JSON.stringify — объект в строку. JSON.parse — строка в объект. Эту пару надо помнить наизусть, они используются везде.

Проверка на пустоту

Если ключа нет, getItem вернёт null. Обычно делают так:

const raw = localStorage.getItem("count");
const count = raw ? Number(raw) : 0;

Или для объектов:

const user = JSON.parse(localStorage.getItem("user") || "{}");

Если ключа нет — вернётся "{}" и JSON.parse даст пустой объект.

Пример: счётчик, который помнит себя

let count = Number(localStorage.getItem("count")) || 0;
const display = document.getElementById("count");
display.textContent = count;

document.getElementById("plus").addEventListener("click", () => {
  count++;
  display.textContent = count;
  localStorage.setItem("count", count);
});

Перезагрузи страницу — счётчик останется. Закрой браузер, открой снова — тоже.

Пример: список задач

const input = document.querySelector("#task-input");
const list = document.querySelector("#task-list");

// загрузить при старте
let tasks = JSON.parse(localStorage.getItem("tasks") || "[]");
renderTasks();

function renderTasks() {
  list.innerHTML = "";
  tasks.forEach((task, i) => {
    const li = document.createElement("li");
    li.textContent = task;
    li.addEventListener("click", () => {
      tasks.splice(i, 1);
      saveTasks();
      renderTasks();
    });
    list.appendChild(li);
  });
}

function saveTasks() {
  localStorage.setItem("tasks", JSON.stringify(tasks));
}

document.querySelector("#add").addEventListener("click", () => {
  if (!input.value.trim()) return;
  tasks.push(input.value.trim());
  input.value = "";
  saveTasks();
  renderTasks();
});

Это уже настоящий todo-лист. Он сохраняется между сессиями. Вот так работают реальные приложения.

sessionStorage и cookies

  • localStorage — хранится, пока пользователь не очистит. Не имеет срока. Много места (~5–10 МБ);
  • sessionStorage — тот же API, но данные живут до закрытия вкладки;
  • cookies — маленькие данные, отправляются на сервер при каждом запросе. Устаревший способ для клиентского хранения.

Для своих проектов почти всегда localStorage.

Ограничения

  • Только строки;
  • Около 5–10 МБ на сайт;
  • Хранится в браузере, не на сервере. Если пользователь очистит данные — всё пропадёт;
  • Нельзя использовать для паролей и чувствительных данных;
  • Работает только для файлов, открытых через один и тот же путь (если перенести HTML в другую папку — данные не найдутся).

Важный нюанс для твоей обучалки

Твоя обучалка уже использует localStorage — та самая app.js, которую мы писали. Ключ "local-adaptation-v1" — под ним хранится всё твоё: прогресс, заметки, ответы. Поэтому, если очистить данные браузера, всё пропадёт. Так что раз в неделю делай бэкап через «Экспорт JSON» — на всякий случай.

Что важно запомнить

  • setItem / getItem / removeItem / clear;
  • Хранит только строки;
  • JSON.stringify + JSON.parse — для объектов;
  • getItem возвращает null, если ключа нет;
  • localStorage — постоянный, sessionStorage — до закрытия вкладки;
  • Для чувствительных данных — не использовать.
✦ домашка

Цель: сделать три штуки, которые помнят себя после перезагрузки.

  • Создай файл storage.html + style.css + script.js.
  • Проект 1 — счётчик с памятью:
    • кнопки «+» и «−»;
    • при старте загружай значение из localStorage;
    • при каждом клике — сохраняй;
    • обнови страницу — значение должно остаться;
    • бонус: кнопка «сброс», которая очищает и localStorage.
  • Проект 2 — тема с памятью:
    • кнопка переключения светлая/тёмная;
    • при старте страница должна уже быть в той теме, которую выбрал в прошлый раз;
    • при переключении — сохраняй в localStorage.
  • Проект 3 — список задач:
    • поле ввода + кнопка «добавить»;
    • список задач;
    • при старте — загружай из localStorage;
    • при добавлении и удалении — сохраняй;
    • бонус: клик по задаче удаляет её;
    • бонус 2: если задач нет — покажи «пока пусто».
  • Главное: попробуй сохранить в localStorage объект (через JSON.stringify) и прочитать его обратно (через JSON.parse). Убедись, что свойства на месте.
  • Проверка: открой F12 → Application → Local Storage. Ты увидишь свои данные вживую. Так удобно проверять, что всё сохраняется.
  • Важный момент: в твоей обучалке уже используется localStorage. Открой Application → Local Storage → ключ local-adaptation-v1 — там лежат твои ответы. Не удаляй их случайно.
