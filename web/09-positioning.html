Позиционирование элементов

static, relative, absolute, fixed, sticky
главная› Web›09
◈ теория

Обычно элементы идут друг за другом сверху вниз — это нормальный поток. Но иногда нужно вырвать элемент из потока и поставить в конкретное место. Для этого есть свойство position.

У него пять значений. Разберём каждое.

1. static — по умолчанию

Элемент стоит в обычном потоке. Свойства top, left, right, bottom не работают.

.box { position: static; }

2. relative — относительно себя

Элемент остаётся в потоке, но его можно сдвинуть от его обычного места через top/left/right/bottom. Соседние элементы при этом не сдвигаются — как будто элемент всё ещё там.

.box {
  position: relative;
  top: 10px;
  left: 20px;
}

Часто relative используют как «якорь» для absolute внутри (см. ниже).

3. absolute — относительно ближайшего родителя с position

Элемент вырывается из потока — соседи его «не видят». Позиционируется относительно ближайшего родителя, у которого position не static (обычно relative). Если такого нет — относительно всей страницы.

.parent { position: relative; }
.child {
  position: absolute;
  top: 0;
  right: 0;
}

Так делают бейджики, иконки в углу карточки, всплывашки.

4. fixed — относительно окна

Элемент «прилипает» к окну браузера и не двигается при скролле. Идеально для кнопки «наверх», плавающего меню, чата поддержки.

.back-to-top {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

5. sticky — гибрид relative и fixed

Элемент ведёт себя как relative, пока не дойдёт до заданной границы, а потом «прилипает» к ней при скролле. Нужно указать хотя бы top.

.header {
  position: sticky;
  top: 0;
}

Так делают залипающие заголовки, меню, оглавления.

z-index — кто выше

Когда элементы перекрываются, важен порядок «слоёв». z-index управляет этим — но работает только у элементов с position, кроме static.

.modal {
  position: fixed;
  z-index: 999; /* поверх всего */
}

Чем больше число — тем выше слой.

Как не запутаться

  • По умолчанию — static. Ничего не делай, если и так устраивает.
  • Хочешь немного сдвинуть — relative.
  • Хочешь повесить в угол родителя — absolute + родителю relative.
  • Хочешь, чтобы всегда было на экране — fixed.
  • Хочешь, чтобы прилипало при скролле — sticky.
✦ домашка

Цель: попробовать каждое значение position руками.

  • Создай файл positioning.html + style.css.
  • В HTML сделай:
    • несколько обычных абзацев, чтобы был скролл;
    • блок <div class="parent"> с <div class="badge"> внутри;
    • кнопку <button class="fixed-btn">↑</button>;
    • заголовок <h2 class="sticky-title"> где-нибудь в середине.
  • Примени:
    • .parent { position: relative; height: 200px; background: ...; };
    • .badge { position: absolute; top: 10px; right: 10px; } — посмотри, как бейджик висит в углу;
    • .fixed-btn { position: fixed; bottom: 20px; right: 20px; } — прокрути страницу, кнопка должна «стоять»;
    • .sticky-title { position: sticky; top: 0; } — прокрути и посмотри, как заголовок прилипает.
  • Проверка relative: сделай абзац с position: relative; top: 20px; — убедись, что он сдвинулся, но место за ним осталось.
  • Проверка z-index: сделай два перекрывающихся блока с разными z-index — посмотри, какой выше.
  • Главное задание: сделай карточку с «бейджиком новинки» в углу — это самое частое применение absolute. Это должно остаться как мини-навык.
