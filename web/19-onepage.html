Одностраничный сайт

всё на одной странице, со скроллом по секциям
главная› Web›19
◈ теория

Одностраничник (landing) — это сайт, где вся информация лежит на одной длинной странице, а меню не перезагружает её, а плавно скроллит к нужной секции. Так делают почти все современные лендинги.

Эта тема — сборка всего, что ты выучила: структура, ссылки, CSS, Flexbox, Grid, анимации, адаптив. Это твой первый настоящий макет.

Структура типичного лендинга

  • Header — фиксированная шапка с логотипом и меню;
  • Hero — первый большой экран. Заголовок, подзаголовок, кнопка;
  • Features — три-четыре преимущества (иконка + заголовок + текст);
  • Gallery — картинки или карточки;
  • About — текст о проекте;
  • Contact / CTA — форма или кнопка «связаться»;
  • Footer — копирайт и ссылки.

Якорные ссылки — сердце одностраничника

Каждой секции даёшь id:

<section id="features">...</section>

А в меню — ссылка на этот id:

<a href="#features">Возможности</a>

Браузер плавно проскроллит к секции — если добавить в CSS:

html {
  scroll-behavior: smooth;
}

Одна строка, а ощущение — как в дорогом сайте.

Fixed-шапка

header {
  position: fixed;
  top: 0; left: 0; right: 0;
  z-index: 100;
  background: rgba(18,10,20,0.85);
  backdrop-filter: blur(10px);
}

backdrop-filter: blur() — стеклянный эффект. Работает во всех современных браузерах.

Чтобы контент не «уезжал» под шапку, добавь отступ:

body { padding-top: 70px; }

Или scroll-padding-top: 70px; — если хочешь, чтобы при скролле к якорям оставалось место под шапкой.

Hero — первый экран

Классика: min-height: 100vh, центрирование через Flexbox, крупный заголовок, кнопка.

.hero {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  text-align: center;
  padding: 40px 20px;
}

Секции и «воздух»

section {
  padding: 80px 20px;
  max-width: 1100px;
  margin: 0 auto;
}

Вертикальный padding 60–100px — то, что отличает «любительский» сайт от «нормального». Не бойся пустого места.

Карточки преимуществ

Сетка через Grid или Flexbox:

.features {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}

Три-четыре карточки с иконкой, заголовком и текстом.

Появление при скролле

Красиво, когда секции «всплывают» при прокрутке. Простой способ:

.section {
  opacity: 0;
  transform: translateY(30px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.section.visible {
  opacity: 1;
  transform: translateY(0);
}

А класс .visible добавляется через JS при появлении в зоне видимости. Это Intersection Observer — про него в теме 23.

Пока можно сделать проще: класс .visible поставить сразу в HTML и добавить анимацию fadeUp из темы 17.

Footer

footer {
  padding: 40px 20px;
  text-align: center;
  color: var(--muted);
  border-top: 1px solid var(--line);
}

Что важно запомнить

  • Каждой секции — id, в меню — #id;
  • scroll-behavior: smooth; — плавный скролл одной строкой;
  • position: fixed; + z-index для шапки;
  • Hero — 100vh + Flexbox-центр;
  • Много padding у секций — секрет «дорогого» вида;
  • Карточки — через repeat(auto-fit, minmax(240px, 1fr)).
✦ домашка

Цель: собрать свой первый настоящий одностраничник. Это уже портфолио-работа.

  • Создай папку landing, внутри index.html и style.css.
  • Придумай тему: личная страница, страница проекта, сайт-визитка, страница о хобби — что угодно, но своё.
  • Структура:
    • <header> с фиксированной шапкой и 4 якорными ссылками;
    • <section id="hero"> — крупный заголовок, подзаголовок, кнопка;
    • <section id="features"> — 3–4 карточки с преимуществами;
    • <section id="gallery"> — 4–6 карточек или картинок;
    • <section id="about"> — текст о проекте;
    • <section id="contact"> — кнопка или простая форма;
    • <footer> — копирайт.
  • Стиль: тёмная тема, акцент — розовый/фиолетовый (как у твоей обучалки).
  • CSS-требования:
    • html { scroll-behavior: smooth; };
    • фиксированная шапка с backdrop-filter;
    • Hero — min-height: 100vh, центрирование через Flexbox;
    • features — через repeat(auto-fit, minmax(240px, 1fr));
    • img { max-width: 100%; height: auto; display: block; };
    • хотя бы одна CSS-анимация (fadeUp, pulse или glow);
    • @media (prefers-reduced-motion: reduce) — отключить анимации;
    • адаптив через clamp() для заголовка.
  • Главная проверка: прогони через DevTools (Ctrl+Shift+M) на iPhone SE, iPad и Desktop. Ничего не должно ломаться.
  • Бонус: сделай появление секций при скролле через @keyframes fadeUp — пока просто примени её к секциям при загрузке.
