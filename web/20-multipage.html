Многостраничный сайт

несколько страниц, общее меню, правильные пути
главная› Web›20
◈ теория

Одностраничник — хорошо для лендинга, но для настоящего сайта нужны отдельные страницы: главная, о нас, портфолио, контакты. Это многостраничный сайт.

Структура папок

Правильная структура — половина успеха. Классика такая:

my-site/
├── index.html          ← главная
├── about.html
├── portfolio.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
    ├── logo.png
    └── hero.jpg

Все страницы — в корне. Стили, скрипты и картинки — в своих папках. Никаких файлов «в куче».

Пути — как не сломать ссылки

Это самое частое, где спотыкаются. Правило простое:

  • Относительно текущего файла: about.html — файл рядом; css/style.css — в папке;
  • На уровень выше: ../index.html — если ты в подпапке;
  • Абсолютный: /about.html — от корня сайта (работает только на сервере, локально — нет);
  • Полный URL: https://example.com — внешний сайт.

Все страницы лежат в одной папке → пути между ними простые: href="about.html". Так и делай.

Общее меню на всех страницах

В каждой странице — одинаковый <header> с меню. Да, копипаста. В реальных проектах её решают шаблонизаторы (Jekyll, Eleventy, Astro), но без сервера — только копия.

<header>
  <nav>
    <a href="index.html">главная</a>
    <a href="about.html">обо мне</a>
    <a href="portfolio.html">портфолио</a>
    <a href="contact.html">контакты</a>
  </nav>
</header>

Как отметить активную страницу

Чтобы пользователь понимал, где он. Просто добавь класс вручную на каждой странице:

<a href="about.html" class="active">обо мне</a>
nav a.active {
  color: var(--pink);
  border-bottom: 2px solid var(--pink);
}

Один CSS — все страницы

Это главное удобство: css/style.css подключается к каждой странице, и правки применяются ко всем сразу.

<link rel="stylesheet" href="css/style.css">

Базовые страницы любого сайта

  • Главная — hero, кратко о проекте, CTA;
  • О нас — текст, команда, история;
  • Портфолио / услуги — сетка карточек;
  • Контакты — форма, ссылки на соцсети;
  • 404 — страница «не найдено» (на будущее).

Как опубликовать в интернете

Локально сайт работает просто из папки. А чтобы поделиться с миром — есть бесплатные хостинги:

  • GitHub Pages — загружаешь папку на GitHub, включаешь Pages в настройках, получаешь ссылку. Самый популярный способ для статики;
  • Netlify — перетаскиваешь папку мышкой в браузер, получаешь ссылку через 10 секунд;
  • Vercel — похоже, с авто-деплоем из GitHub.

Для всех трёх нужна только папка с HTML/CSS/JS — ничего настраивать не надо.

Что важно запомнить

  • Страницы — в корне, ресурсы — по папкам;
  • Пути простые, если всё в одной папке: about.html;
  • Меню копируется на каждую страницу;
  • Активная страница — через класс .active;
  • Один CSS на все страницы — экономит часы;
  • Опубликовать можно бесплатно на GitHub Pages или Netlify.
✦ домашка

Цель: сделать многостраничный сайт из 3–4 страниц с общим меню и стилями.

  • Создай папку my-site и внутри: 
    my-site/
├── index.html
├── about.html
├── portfolio.html
├── contact.html
├── css/
│   └── style.css
└── images/
  • В каждой странице:
    • одинаковый <header> с меню из 4 пунктов;
    • одинаковый <footer>;
    • подключён css/style.css.
  • Содержимое страниц:
    • index — hero-секция с крупным заголовком и кнопкой;
    • about — текст «обо мне» + картинка;
    • portfolio — сетка из 6 карточек через repeat(auto-fit, minmax(240px, 1fr));
    • contact — форма с именем, email, сообщением.
  • В меню на каждой странице добавь class="active" на текущую страницу. Стилизуй nav a.active.
  • Стили — тёмная тема, розово-фиолетовый акцент. Один файл, общий для всех страниц.
  • Проверка путей: пройди по всем ссылкам меню — все страницы должны открываться, никаких 404.
  • Главная: открой проект в браузере, походи по страницам, проверь, что меню и футер везде одинаковые, стили подхватились.
  • Бонус: загрузи папку на GitHub Pages или Netlify и получи публичную ссылку. Это уже настоящий сайт, которым можно поделиться.
