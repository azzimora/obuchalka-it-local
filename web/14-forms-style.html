Стилизация форм

как сделать поля красивыми и удобными
главная› Web›14
◈ теория

По умолчанию поля формы выглядят как из 90-х: серые, угловатые, со странными рамками. Но их можно полностью переодеть в CSS. Это, пожалуй, самая «благодарная» тема — результат виден сразу.

Сброс стилей браузера

Браузеры добавляют свои стили для форм. Первое, что делают, — «обнуляют» их:

input, textarea, select, button {
  font: inherit;
  color: inherit;
  border: none;
  background: none;
  outline: none;
}

font: inherit — чтобы поля использовали тот же шрифт, что и страница. Иначе они «живут своей жизнью».

Базовый вид поля

input, textarea, select {
  width: 100%;
  padding: 12px 14px;
  background: #1a0f1e;
  border: 1px solid rgba(255,142,199,0.2);
  border-radius: 10px;
  color: #f3e8f5;
  font-size: 1rem;
  transition: border-color 0.2s, box-shadow 0.2s;
}

Обрати внимание на transition — это чтобы фокус появлялся плавно, а не резко.

Состояние фокуса — :focus

Когда человек кликает в поле, оно получает фокус. Это надо подсветить — иначе непонятно, куда ты пишешь.

input:focus, textarea:focus, select:focus {
  border-color: #ff8ec7;
  box-shadow: 0 0 0 3px rgba(255,142,199,0.35);
}

box-shadow с нулевым смещением работает как «свечение вокруг» — очень удобный приём.

Плейсхолдер

::placeholder {
  color: #a889b0;
  opacity: 0.6;
}

По умолчанию он часто слишком яркий — приглуши, чтобы не путали с введённым текстом.

Кнопка

button {
  padding: 12px 24px;
  background: linear-gradient(135deg, #ff8ec7, #c77dff);
  color: #1a0f1d;
  font-weight: 600;
  border-radius: 10px;
  cursor: pointer;
  transition: transform 0.15s, box-shadow 0.2s;
}
button:hover {
  box-shadow: 0 6px 20px rgba(255,142,199,0.35);
}
button:active {
  transform: scale(0.97);
}

:hover — при наведении; :active — в момент нажатия. Мелочь, но она делает интерфейс «живым».

Чекбоксы и радио

Стандартные чекбоксы плохо стилизуются. Обычно их скрывают и рисуют свой вид через псевдо-элементы. Простой способ:

input[type="checkbox"] {
  appearance: none;
  width: 20px;
  height: 20px;
  border: 2px solid #a889b0;
  border-radius: 6px;
  cursor: pointer;
  position: relative;
  transition: all 0.2s;
}
input[type="checkbox"]:checked {
  background: linear-gradient(135deg, #ff8ec7, #c77dff);
  border-color: #ff8ec7;
}
input[type="checkbox"]:checked::after {
  content: "✓";
  position: absolute;
  inset: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #1a0f1d;
  font-size: 0.85rem;
}

appearance: none убирает стандартный вид — дальше рисуем как хотим.

Сетка формы

Формы удобно верстать через Grid или Flexbox:

form {
  display: grid;
  gap: 16px;
  max-width: 500px;
}
.field-row {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 12px;
}

Так два поля «Имя» и «Фамилия» встанут рядом, а остальные — друг под другом.

Доступность — не забывай

  • Каждое поле должно иметь <label>;
  • Не убирай outline без замены — это ломает навигацию с клавиатуры;
  • Кнопка отмены/отправки — достаточно крупная, минимум 44×44px;
  • Цвет текста и фона — контрастные.

Что важно запомнить

  • font: inherit — обязательно;
  • :focus с box-shadow — обязательная подсветка;
  • transition — чтобы всё было плавно;
  • appearance: none — для кастомных чекбоксов;
  • Форма — это тоже Grid/Flexbox, не изобретай велосипед.
✦ домашка

Цель: сделать красивую форму регистрации — такую, чтобы не стыдно показать.

  • Создай файл forms-styled.html + style.css.
  • Сделай форму с полями: имя, email, пароль, город (select), о себе (textarea), чекбокс «согласен», кнопка «зарегистрироваться».
  • Сначала сбрось стили: 
    input, textarea, select, button {
  font: inherit;
  color: inherit;
  border: none;
  background: none;
  outline: none;
}
  • Задай базовый вид полям: padding, border, border-radius, background. Фон и цвет — в стиле твоей обучалки (тёмная тема с розовым акцентом).
  • Добавь :focus с box-shadow — поле должно подсвечиваться розовым.
  • Затемни ::placeholder — пусть он будет приглушённый, не мешает.
  • Сделай кнопку с градиентом, :hover (тень) и :active (сжатие).
  • Стилизуй чекбокс через appearance: none + :checked + ::after с галочкой.
  • Сверстай форму через display: grid; gap: 16px;. А поля «имя» и «email» поставь в один ряд через grid-template-columns: 1fr 1fr;.
  • Главное: сфокусируйся в каждом поле Tab'ом — должно быть видно, куда перешёл фокус. Если нет — верни :focus.
  • Бонус: сделай input:invalid (например, email без @) — красную рамку. И input:valid — зелёную.
