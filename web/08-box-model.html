Блочная модель

padding, border, margin — где что
главная› Web›08
◈ теория

Каждый элемент на странице — это прямоугольная коробка. У неё есть четыре слоя, вложенных друг в друга, как матрёшка. Это и есть блочная модель (box model).

Четыре слоя

  • content — сам контент (текст, картинка). Внутренняя часть;
  • padding — внутренний отступ. Пространство между контентом и рамкой. «Надувает» коробку изнутри;
  • border — рамка. Обводка вокруг padding;
  • margin — внешний отступ. Пространство вне рамки. Отодвигает коробку от других.

Аналогия: представь картину в рамке, висящую на стене. Картина — content. Паспарту (белое поле вокруг картины внутри рамки) — padding. Сама рамка — border. Расстояние до соседней картины — margin.

Как задавать

.card {
  width: 300px;        /* ширина контента */
  padding: 20px;       /* со всех сторон */
  border: 2px solid pink;
  margin: 16px;
}

Можно задавать стороны по отдельности:

padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

Или коротко:

padding: 10px 20px;        /* верх/низ · лево/право */
padding: 10px 20px 30px;   /* верх · лево/право · низ */
padding: 10px 20px 30px 40px; /* верх · право · низ · лево (по часовой) */

То же самое работает для margin.

Центрирование блока

Если у блока есть width, его можно отцентрировать так:

margin: 0 auto;

auto слева и справа = равные отступы = по центру.

box-sizing — самая частая ловушка

По умолчанию width: 300px — это ширина только контента. Если добавить padding: 20px и border: 2px, реальная ширина станет 300 + 40 + 4 = 344px. Многие на этом спотыкаются.

Решение — box-sizing:

* {
  box-sizing: border-box;
}

Тогда width: 300px — это вся коробка, включая padding и border. Гораздо удобнее, и почти все проекты так и пишут.

Схлопывание margin (margin collapse)

Вертикальные margin соседних блоков «схлопываются»: если у одного margin-bottom: 20px, а у другого margin-top: 30px, между ними будет не 50, а 30 — большее из двух. Это нормальное поведение, не баг.

Как посмотреть блочную модель

F12 → выбери элемент → вкладка «Computed» или «Layout» — увидишь цветную схему с content / padding / border / margin. Очень помогает, когда что-то «не туда встало».

✦ домашка

Цель: почувствовать каждое кольцо блочной модели.

  • Создай файл box-model.html + style.css.
  • Сразу добавь в CSS: 
    * { box-sizing: border-box; }
  • В HTML сделай три блока <div class="box"> с коротким текстом внутри.
  • Поэкспериментируй:
    • первому блоку — padding: 20px; и фон посветлее. Заметь, как текст «отодвинулся» от краёв;
    • второму — border: 3px solid pink;. Заметь, где именно рамка;
    • третьему — margin: 40px;. Заметь, как он отодвинулся от соседей;
    • первому — width: 300px; margin: 0 auto;. Заметь центрирование.
  • Проверка box-sizing: задай блоку width: 300px; padding: 40px; border: 5px solid;. Открой DevTools → Computed — убедись, что итоговая ширина ровно 300px.
  • Проверка схлопывания: сделай два блока с margin-bottom: 40px; и margin-top: 20px; между ними. Замерь в DevTools — увидишь 40, а не 60. Запиши это в конспект.
  • Главное: открой DevTools → найди любой блок → во вкладке Elements посмотри цветную схему блочной модели. Потыкай значения прямо там — увидишь, как меняется страница в реальном времени.
