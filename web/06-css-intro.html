Введение в CSS

как одеть HTML в красоту
главная› Web›06
◈ теория

HTML — это скелет: структура, теги, смысл. CSS (Cascading Style Sheets) — это внешность: цвета, размеры, отступы, шрифты, расположение.

Одна и та же HTML-страница без CSS выглядит как документ из 90-х: чёрный текст на белом, всё в столбик. С CSS — как что угодно, что ты захочешь.

Как подключить CSS

Три способа. Мы будем пользоваться третьим — он правильный.

1. Внутри тега (inline, плохо):

<p style="color: red;">текст</p>

2. Внутри <style> в head (нормально для маленьких страниц):

<style>
  p { color: red; }
</style>

3. Отдельный файл (правильно для проектов):

<link rel="stylesheet" href="style.css">

Этот тег кладётся в <head>. В файле style.css — только CSS, без HTML.

Анатомия CSS-правила

селектор {
  свойство: значение;
  свойство: значение;
}

Пример:

h1 {
  color: pink;
  font-size: 40px;
  text-align: center;
}

Что здесь что:

  • селектор — кого стилизуем (h1 — все заголовки первого уровня);
  • свойство — что меняем (color, font-size);
  • значение — на что меняем (pink, 40px);
  • точка с запятой после каждого свойства — обязательно.

Три базовых селектора

  • по тегу: p { ... } — все абзацы;
  • по классу: .card { ... } — все элементы с class="card";
  • по id: #header { ... } — один элемент с id="header".

Класс можно вешать на сколько угодно элементов. Id — только один на странице. Поэтому в реальной работе почти всегда используют классы.

Первые свойства, которые пригодятся

  • color — цвет текста;
  • background — цвет фона;
  • font-size — размер шрифта (в px или rem);
  • font-family — шрифт;
  • text-align — выравнивание (left, center, right);
  • padding — внутренний отступ;
  • margin — внешний отступ;
  • border — рамка.

Цвета — как их задавать

  • по имени: red, pink, black — просто, но мало вариантов;
  • HEX: #ff8ec7 — шесть символов, самый частый способ;
  • rgb: rgb(255, 142, 199) — три числа от 0 до 255.

Совет: HEX-цвета удобно подбирать в палитре Google или в любом color-picker'е.

✦ домашка

Цель: почувствовать разницу между HTML и CSS и научиться подключать стили.

  • Создай папку css-practice, внутри:
    • index.html — с обычным каркасом;
    • style.css — пустой файл.
  • В <head> подключи стили через <link rel="stylesheet" href="style.css">.
  • В HTML сделай:
    • заголовок <h1>;
    • два абзаца <p>;
    • блок <div class="card"> с любым текстом внутри.
  • В CSS сделай:
    • заголовку — свой цвет, размер и центрирование;
    • первому абзацу — один цвет, второму — другой (используй классы);
    • блоку .card — фон, внутренний отступ, рамку и скруглённые углы (border-radius).
  • Эксперимент: поменяй одно значение — например, color у заголовка — и обнови страницу. Убедись, что CSS применяется мгновенно.
  • Проверка: специально сделай ошибку — забудь точку с запятой. Посмотри, что перестало работать. Это научит внимательности.
