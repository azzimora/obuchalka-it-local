CSS Grid — основы

двумерные сетки — то, что Flexbox не умеет
главная› Web›12
◈ теория

Flexbox — одномерный: либо ряд, либо столбик. Grid — двумерный: строки и столбцы одновременно. Когда нужно построить настоящую сетку — Grid незаменим.

Главная идея

Ты говоришь родителю: «стань grid», и описываешь, сколько столбцов и какой ширины.

.container {
  display: grid;
  grid-template-columns: 200px 200px 200px;
}

Всё. Дети автоматически разложатся по три в ряд.

grid-template-columns — столбцы

  • grid-template-columns: 200px 200px 200px; — три столбца по 200px;
  • grid-template-columns: 1fr 1fr 1fr; — три равных столбца (fr = «доля свободного места»);
  • grid-template-columns: 240px 1fr; — сайдбар 240px + растягивающийся контент;
  • grid-template-columns: repeat(3, 1fr); — то же самое, что три раза по 1fr;
  • grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); — магия: сколько влезет столбцов минимум по 200px.

Что такое fr

fr = fraction. Доля свободного места. Если 1fr 2fr — первый получит ⅓, второй ⅔. Работает как flex-grow, но для столбцов/строк.

grid-template-rows — строки

.container {
  grid-template-rows: 100px 200px auto;
}

Работает так же, но для строк. Если не задавать — строки создаются автоматически по высоте контента.

gap — промежутки

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

Можно раздельно: row-gap и column-gap.

Классический layout страницы

.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr 40px;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  min-height: 100vh;
  gap: 0;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

grid-template-areas — очень наглядно: ты буквально рисуешь сетку текстом. Одинаковые имена = одна область.

Выравнивание внутри grid

  • justify-items: center; — выровнять всё по горизонтали внутри ячеек;
  • align-items: center; — по вертикали;
  • place-items: center; — то и то сразу;
  • justify-content / align-content — выравнивание всей сетки, если она меньше контейнера.

Когда Grid, когда Flexbox

  • Flexbox — когда элементы в одну линию и важно распределение пространства вдоль неё (навбары, кнопки, карточки в ряд).
  • Grid — когда нужна структура из строк и столбцов (макет страницы, галерея, таблица-подобное).
  • Они хорошо сочетаются: страница на Grid, внутри блоков — Flexbox.

Адаптивная сетка без media-запросов

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}

Это одна строка, которая заменяет кучу media-запросов. Карточки сами перестраиваются в зависимости от ширины окна. Запомни это — пригодится везде.

Шпаргалка

  • Grid — display: grid;.
  • Столбцы — grid-template-columns.
  • Промежутки — gap.
  • Адаптив — repeat(auto-fit, minmax(200px, 1fr)).
  • Макет страницы — grid-template-areas.
✦ домашка

Цель: собрать три разных сетки — простую, адаптивную и layout страницы.

  • Создай файл grid.html + style.css.
  • Упражнение 1 — простая сетка 3×3: grid-template-columns: repeat(3, 1fr); + 9 блоков. Убедись, что получилось 3 строки по 3.
  • Упражнение 2 — fr: сделай grid-template-columns: 1fr 2fr; и grid-template-columns: 200px 1fr;. Сравни, как меняется.
  • Упражнение 3 — адаптивная галерея: сделай 6–9 карточек с grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); и gap: 16px;. Сузь окно — карточки перестроятся сами.
  • Макет страницы: сделай grid-layout с шапкой, сайдбаром, контентом и футером через grid-template-areas. Это классическая структура сайта, которую ты теперь умеешь.
  • Центрирование: сделай grid 1×1 и отцентрируй блок через place-items: center; + min-height: 100vh;. Сравни с flex-подходом — что короче?
  • Главное: сделай простой дашборд: шапка, слева меню, справа 4 карточки-виджета в сетке 2×2. Это выглядит как настоящий интерфейс, и собрать его теперь — 20 минут.
