Flexbox — основы

как расставить элементы в ряд без боли
главная› Web›10
◈ теория

До Flexbox выстроить элементы в ряд было больно: float'ы, clearfix'ы, магические хаки. Flexbox решил это раз и навсегда. Сейчас это основной инструмент вёрстки.

Главная идея

Ты говоришь родителю: «стань flex-контейнером», а его дети автоматически выстраиваются в ряд (или в столбик) и распределяются по правилам, которые ты задаёшь.

.container {
  display: flex;
}

Всё. После этого дети .container встают в один ряд.

Две оси

У flex-контейнера есть две оси:

  • main axis (главная) — по умолчанию горизонтальная;
  • cross axis (поперечная) — по умолчанию вертикальная.

Всё управление — это «как распределить по главной» и «как выровнять по поперечной».

flex-direction — куда ряд

  • row (по умолчанию) — слева направо;
  • column — сверху вниз;
  • row-reverse — справа налево;
  • column-reverse — снизу вверх.

justify-content — выравнивание по главной оси

  • flex-start — прижать к началу;
  • flex-end — прижать к концу;
  • center — по центру;
  • space-between — крайние по краям, между ними равные промежутки;
  • space-around — равные отступы вокруг каждого;
  • space-evenly — равные промежутки везде.

align-items — выравнивание по поперечной оси

  • stretch (по умолчанию) — растянуть на всю высоту;
  • flex-start — к верху;
  • flex-end — к низу;
  • center — по центру.

gap — промежутки между элементами

.container {
  display: flex;
  gap: 16px;
}

gap — самый удобный способ задать отступы между flex-элементами. Раньше для этого использовали margin и мучились с крайними.

flex-wrap — если не влезает

По умолчанию элементы сжимаются в одну строку. flex-wrap: wrap разрешает переносить их на новую строку, если не хватает места.

.container {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}

Это база для адаптивных карточек.

Свойства детей

  • flex: 1 — занять всё свободное место поровну с другими;
  • flex-grow — как сильно растягиваться;
  • flex-shrink — как сильно сжиматься;
  • flex-basis — базовый размер до распределения;
  • align-self — переопределить align-items для одного ребёнка.

Классический паттерн

Отцентрировать что-то и по горизонтали, и по вертикали:

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

Раньше это было сложно. С Flexbox — три строки.

Шпаргалка

  • Ряд — display: flex;.
  • Центр — justify-content: center; align-items: center;.
  • Промежутки — gap: ...;.
  • Перенос — flex-wrap: wrap;.
  • Равные ширины — flex: 1; у детей.
✦ домашка

Цель: почувствовать flex руками — это половина всей вёрстки.

  • Создай файл flexbox.html + style.css.
  • Сделай контейнер <div class="row"> с тремя блоками внутри.
  • Поочерёдно применяй и записывай, что меняется:
    • display: flex; — элементы встали в ряд;
    • gap: 16px; — появились промежутки;
    • justify-content: center; — по центру;
    • justify-content: space-between; — по краям;
    • align-items: center; — выровнялись по вертикали (сделай блоки разной высоты, чтобы было видно);
    • flex-direction: column; — встали в столбик.
  • Сделай навбар: слева логотип, справа меню из 3 ссылок. Через justify-content: space-between;. Это классика.
  • Сделай три карточки в ряд с flex: 1 — они должны стать одинаковой ширины.
  • Сделай центрирование по центру экрана: один блок, min-height: 100vh;, и через flex — по центру и по горизонтали, и по вертикали.
  • Главное: открой DevTools, найди flex-контейнер — там есть специальная «flex-панель», где можно тыкать justify-content мышкой. Попробуй, это ускоряет обучение.
