JavaScript — основы

переменные, типы, условия, циклы, функции
главная› Web›21
◈ теория

HTML — структура, CSS — внешность, JavaScript — поведение. Это язык программирования, который делает страницу живой: реагирует на клики, считает, меняет содержимое, общается с сервером.

Это не «разметка», как HTML, и не «стили», как CSS. Это полноценный язык, и учиться ему — как учиться новому разговору.

Как подключить

Внутри HTML, перед закрывающим </body>:

<script>
  console.log("привет");
</script>

Или отдельным файлом (правильно для проектов):

<script src="js/script.js"></script>

Важно: скрипт подключается в конце <body>, а не в <head> — чтобы HTML успел загрузиться до того, как JS начнёт с ним работать.

console.log — твой лучший друг

Выводит что угодно в консоль браузера (F12 → Console). Это способ «посмотреть, что происходит внутри».

console.log("привет, мир");
console.log(2 + 2);

Переменные

Контейнеры для значений. Два ключевых слова:

let age = 17;        // можно менять
const name = "Аня";  // нельзя переприсвоить

Правило современного JS: по умолчанию используй const, а let — только если значение будет меняться. Старое var не используй.

Типы данных

  • string — строка: "привет", 'JS', `шаблон`;
  • number — число: 42, 3.14, -7;
  • boolean — true / false;
  • null — «пусто, но намеренно»;
  • undefined — «значение не задано»;
  • object — объект: { name: "Аня", age: 17 };
  • array — массив: [1, 2, 3].

Шаблонные строки

Обратные кавычки позволяют вставлять значения прямо в текст:

const name = "Аня";
console.log(`Привет, ${name}!`);

Гораздо удобнее, чем склеивать через +.

Операторы

  • Арифметика: + - * / % (% — остаток от деления);
  • Сравнение: === (строгое равно), !==, >, <;
  • Логика: && (и), || (или), ! (не).

Всегда используй ===, а не == — второе делает странные преобразования типов.

Условия

if (age >= 18) {
  console.log("совершеннолетний");
} else if (age >= 14) {
  console.log("подросток");
} else {
  console.log("ребёнок");
}

Тернарный оператор — короткая запись:

const status = age >= 18 ? "взрослый" : "ребёнок";

Циклы

for — когда знаешь, сколько раз:

for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}

while — пока условие истинно:

let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}

for...of — пройтись по массиву:

const fruits = ["яблоко", "груша", "слива"];
for (const fruit of fruits) {
  console.log(fruit);
}

Функции

Кусок кода, который можно вызвать по имени.

Обычная функция:

function greet(name) {
  return `Привет, ${name}!`;
}
console.log(greet("Аня"));

Стрелочная функция (современный стиль):

const greet = (name) => `Привет, ${name}!`;

Если одно выражение — можно без return и без фигурных скобок. Если один параметр — можно без круглых.

Функция без параметров:

const sayHi = () => console.log("привет");

Массивы

const nums = [1, 2, 3, 4, 5];
console.log(nums.length);    // 5
console.log(nums[0]);        // 1
nums.push(6);                // добавить в конец
nums.pop();                  // убрать последний

Методы, которые используются постоянно:

  • map — преобразовать каждый элемент;
  • filter — оставить только подходящие;
  • find — найти один;
  • forEach — пройтись по всем;
  • includes — проверить наличие.
const nums = [1, 2, 3, 4, 5];
const doubled = nums.map(n => n * 2);        // [2, 4, 6, 8, 10]
const even = nums.filter(n => n % 2 === 0);  // [2, 4]

Объекты

const user = {
  name: "Аня",
  age: 17,
  city: "Москва"
};
console.log(user.name);
user.age = 18; // можно менять свойства

Что важно запомнить

  • const по умолчанию, let если меняется;
  • === вместо ==;
  • console.log() — твой способ смотреть внутрь;
  • Шаблонные строки через обратные кавычки `...${...}`;
  • Стрелочные функции — современный стиль;
  • map, filter, find, forEach — выучи наизусть.

И главное: JS невозможно выучить «читая». Только писать. Открывай консоль F12 и пробуй каждую строчку из этой темы руками. Это в 10 раз эффективнее, чем просто читать.

✦ домашка

Цель: познакомиться с JS руками через консоль. Пока без HTML — только чистый язык.

  • Создай файл js-basics.html с обычным каркасом. Внизу перед </body> — <script> блок.
  • Открой страницу в браузере, нажми F12 → Console. Это твоя рабочая среда.
  • Упражнение 1 — переменные: 
    const name = "твоё имя";
let age = твой возраст;
console.log(`Меня зовут ${name}, мне ${age} лет`);
  • Упражнение 2 — вычисления: посчитай 2 + 2, 10 % 3, 2 ** 8 (степень). Выведи в консоль.
  • Упражнение 3 — условия: напиши if, который проверяет возраст и выводит «ребёнок / подросток / взрослый». Поиграй со значением age.
  • Упражнение 4 — цикл: выведи в консоль числа от 1 до 20 через for. Потом — только чётные.
  • Упражнение 5 — функция: напиши функцию sum(a, b), которая возвращает сумму. Вызови её с разными числами.
  • Упражнение 6 — массив: сделай массив из 5 чисел. Найди сумму через forEach. Потом сделай новый массив с удвоенными через map.
  • Упражнение 7 — filter: из массива чисел оставь только те, что больше 10.
  • Упражнение 8 — объект: сделай объект me с полями имя, возраст, город, любимый язык. Выведи красивой строкой через шаблонные кавычки.
  • Главное: в консоли можно писать код прямо руками. Попробуй 2 + 2, "a" + "b", [1,2,3].length. Играйся — это лучший способ понять.
  • Бонус — FizzBuzz: классическая задача. Выведи числа от 1 до 30. Если число делится на 3 — «Fizz», на 5 — «Buzz», на 15 — «FizzBuzz», иначе — само число. Если получится — ты уже программист.
