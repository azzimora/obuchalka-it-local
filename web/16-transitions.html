Transitions и Transform

движение, повороты, масштаб — без единой строки JS
главная› Web›16
◈ теория

До этого всё было статичным. Теперь — движение. И самое приятное: без JavaScript. Только CSS.

Два разных инструмента, которые часто путают:

  • transition — плавный переход между двумя состояниями (наведение, фокус, класс). Само движение запускает событие.
  • transform — изменение формы элемента: сдвиг, поворот, масштаб. Что именно делать.

Работают в паре: transform говорит «что», transition — «как плавно».

transition — базовая форма

.btn {
  transition: background 0.3s, transform 0.15s;
}
.btn:hover {
  background: pink;
  transform: scale(1.05);
}

Можно указать:

  • transition: all 0.3s; — всё сразу (просто, но иногда медленно);
  • transition: background 0.3s ease; — конкретное свойство;
  • transition: transform 0.2s ease-in-out 0.1s; — свойство, длительность, кривая, задержка.

Функции плавности (timing function)

  • linear — равномерно;
  • ease — по умолчанию, мягко в обе стороны;
  • ease-in — медленно начинается, ускоряется;
  • ease-out — быстро, замедляется к концу;
  • ease-in-out — мягко с обеих сторон (часто лучший для интерфейсов);
  • cubic-bezier(...) — кастомная кривая.

transform — основные функции

.box {
  transform: translateX(50px);      /* сдвиг по X */
  transform: translateY(20px);      /* сдвиг по Y */
  transform: translate(50px, 20px); /* сразу */
  transform: scale(1.2);            /* увеличить на 20% */
  transform: rotate(45deg);         /* повернуть */
  transform: skew(10deg);           /* наклонить */
}

Комбинирование

Несколько функций через пробел:

transform: translateX(20px) rotate(10deg) scale(1.1);

Порядок важен: он как матрёшка — каждая следующая применяется к результату предыдущей.

transform-origin — точка отсчёта

По умолчанию — центр элемента. Можно сместить:

.box {
  transform-origin: top left;
  transform: rotate(20deg);
}

Классические приёмы

1. Карточка приподнимается при наведении:

.card {
  transition: transform 0.25s ease, box-shadow 0.25s ease;
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 28px rgba(0,0,0,0.25);
}

2. Кнопка сжимается при нажатии:

.btn {
  transition: transform 0.1s;
}
.btn:active {
  transform: scale(0.96);
}

3. Увеличение картинки внутри карточки:

.card { overflow: hidden; }
.card img {
  transition: transform 0.4s ease;
}
.card:hover img {
  transform: scale(1.08);
}

4. Ссылка с подчёркиванием, которое растёт:

a {
  position: relative;
  text-decoration: none;
}
a::after {
  content: "";
  position: absolute;
  left: 0; bottom: -2px;
  width: 0; height: 2px;
  background: pink;
  transition: width 0.3s;
}
a:hover::after {
  width: 100%;
}

Что лучше анимировать

Для плавности используй только transform и opacity — они не пересчитывают layout. Анимация width, height, margin работает, но тормозит, особенно на телефонах.

transition vs animation

  • transition — между двумя состояниями, нужен триггер (:hover, :focus, класс);
  • animation — многошаговая анимация, может идти сама по себе. Про неё — в следующей теме.

Что важно запомнить

  • transition: all 0.3s ease; — быстрый способ;
  • transform: translate / scale / rotate — три главных функции;
  • :hover и :active — любимые триггеры;
  • Анимируй transform и opacity — остальное тормозит;
  • ease-in-out — самая «человечная» кривая.
✦ домашка

Цель: оживить интерфейс — добавить движения, которые делают сайт «живым».

  • Создай файл transitions.html + style.css.
  • Упражнение 1 — кнопка: сделай кнопку. При наведении — меняется фон и появляется тень. При нажатии — scale(0.96). Всё через transition.
  • Упражнение 2 — карточка: сделай карточку, которая при наведении приподнимается на translateY(-6px) и отбрасывает более длинную тень.
  • Упражнение 3 — картинка: карточка с картинкой внутри. При наведении картинка scale(1.1), у карточки overflow: hidden, чтобы зум не вылезал.
  • Упражнение 4 — ссылка: сделай ссылку с растущим подчёркиванием через ::after и width: 0 → 100%.
  • Упражнение 5 — поворот: сделай квадрат, который при наведении rotate(45deg) и превращается в ромб.
  • Бонус — transform-origin: сделай квадрат, который поворачивается вокруг левого верхнего угла (transform-origin: top left). Сравни с обычным поворотом — почувствуй разницу.
  • Главное: собери одну мини-страницу, где всё это вместе — навбар с анимированными ссылками, карточка, кнопка. Это выглядит уже совсем как настоящий сайт.
  • Проверка: если что-то «дёргается» — скорее всего, анимируется width или margin. Поменяй на transform.
