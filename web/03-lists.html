Списки в HTML

маркированные, нумерованные и вложенные
главная› Web›03
◈ теория

Списки — один из самых частых элементов на любой странице. Меню, шаги, перечисления, оглавления — всё это списки. В HTML есть три вида.

1. Маркированный список — <ul>

ul = unordered list (неупорядоченный). Каждый пункт — <li> (list item).

<ul>
  <li>яблоко</li>
  <li>груша</li>
  <li>слива</li>
</ul>

Браузер нарисует точки перед пунктами.

2. Нумерованный список — <ol>

ol = ordered list (упорядоченный). Всё то же самое, но с цифрами.

<ol>
  <li>проснуться</li>
  <li>умыться</li>
  <li>сделать зарядку</li>
</ol>

3. Вложенные списки

Список можно вложить в список. Например, пункт «фрукты» содержит подпункты:

<ul>
  <li>фрукты
    <ul>
      <li>яблоко</li>
      <li>груша</li>
    </ul>
  </li>
  <li>овощи
    <ul>
      <li>морковь</li>
      <li>капуста</li>
    </ul>
  </li>
</ul>

Важно: вложенный <ul> живёт внутри <li>, а не между <li>.

Мелочи, которые пригодятся

  • У <ol> можно сменить тип нумерации через атрибут: <ol type="A"> — заглавные буквы, type="I" — римские цифры.
  • Можно начать нумерацию не с единицы: <ol start="5">.
  • У <ul> тип маркера меняется через CSS, не через HTML.

Правило: внутри <ul> и <ol> могут лежать только <li>. Не текст напрямую, не другие теги — только пункты.

✦ домашка

Цель: научиться строить списки любой сложности.

  • Создай файл lists.html с обычным каркасом.
  • Сделай маркированный список из 5 любимых книг / фильмов / игр.
  • Сделай нумерованный список из 5 шагов какого-нибудь рецепта или утреннего ритуала.
  • Сделай вложенный список: например, «музыка» с подпунктами жанров, «учёба» с подпунктами предметов.
  • Поиграй с атрибутами: сделай <ol type="A"> и <ol start="10">, посмотри разницу.
  • Проверка на внимательность: попробуй написать текст прямо внутри <ul>, без <li>. Посмотри, что будет — и запомни это правило.
