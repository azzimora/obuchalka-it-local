CSS Grid — продолжение

размещение элементов, auto-fill и хитрые сетки
главная› Web›13
◈ теория

В прошлой теме мы строили сетку целиком. Теперь — как положить один элемент в конкретную ячейку или растянуть его на несколько. Это то, что делает Grid незаменимым для сложных макетов.

Линии сетки

У Grid есть линии (grid lines) — они нумеруются. Если 3 столбца, то линий 4: перед первым, между столбцами, после последнего.

grid-template-columns: repeat(3, 1fr);
/* линии: 1 | 2 | 3 | 4 */

grid-column и grid-row

Говорим элементу: «начнись на линии 1, закончись на линии 3».

.wide {
  grid-column: 1 / 3;   /* с 1 по 3 = занимает 2 столбца */
  grid-row: 1 / 2;
}

Можно через span — «занять столько-то ячеек»:

.wide {
  grid-column: span 2;   /* занять 2 столбца */
}

Так проще, потому что не надо считать линии.

Пример: баннер на всю ширину

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 12px;
}
.banner {
  grid-column: 1 / -1;   /* от первой линии до последней */
}

1 / -1 — «от начала до конца». Часто используется для full-width блоков внутри сетки.

auto-fit vs auto-fill

Обе делают адаптивную сетку, но по-разному:

  • repeat(auto-fill, minmax(200px, 1fr)) — создаст столько столбцов, сколько влезет, даже если карточек меньше. Пустые ячейки останутся пустыми, но место под них будет.
  • repeat(auto-fit, minmax(200px, 1fr)) — создаст столбцы под фактическое количество карточек и растянет их. Если карточек мало — они займут всю ширину.

На практике auto-fit чаще нужен именно для галерей: 3 карточки на широком экране займут всё пространство.

min-content, max-content, fit-content

  • min-content — минимальная ширина, при которой контент ещё не ломается (обычно самое длинное слово);
  • max-content — ширина по самому длинному контенту, без переноса;
  • fit-content(300px) — «не больше 300px, но и не меньше нужного».
grid-template-columns: fit-content(300px) 1fr;

Так делают сайдбары, которые «не шире 300, но и не шире, чем нужно».

grid-auto-flow — как идут элементы

  • row (по умолчанию) — заполнение по строкам;
  • column — по столбцам;
  • dense — «уплотнить», заполняя пробелы. Полезно для мозаик.

grid-template-areas снова

Ещё раз — потому что это самый наглядный способ строить макет:

.page {
  display: grid;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  grid-template-columns: 200px 1fr 240px;
  gap: 12px;
}
.header { grid-area: header; }
.nav    { grid-area: nav; }
.main   { grid-area: main; }
.aside  { grid-area: aside; }
.footer { grid-area: footer; }

Точки в areas — пустые ячейки: "header . aside".

Вложенные сетки

Grid-элемент может сам быть grid-контейнером. Так строят сложные интерфейсы: внешняя сетка держит структуру, внутренние — раскладывают контент в карточке.

Что важно запомнить

  • grid-column: span N; — занять N столбцов;
  • 1 / -1 — от начала до конца;
  • auto-fit vs auto-fill — растянуть или оставить пустые;
  • grid-template-areas — самый наглядный способ макета;
  • dense — для мозаик и masonry-подобных сеток.
✦ домашка

Цель: собрать журнальный макет — тот, где одна большая статья и несколько маленьких.

  • Создай файл grid-2.html + style.css.
  • Упражнение 1 — растянуть на 2: сетка 4 столбца, 8 блоков. У второго поставь grid-column: span 2;. Убедись, что он занимает две ячейки.
  • Упражнение 2 — full-width: внутри той же сетки сделай блок с grid-column: 1 / -1; — растянется на всю ширину.
  • Упражнение 3 — auto-fit vs auto-fill: сделай две галереи с 3 карточками. Одна с auto-fill, другая с auto-fit. Сузь окно и сравни: где карточки растягиваются, а где остаются узкими.
  • Макет 1 — «журнал»: сетка 4 столбца. Сделай:
    • большой блок-«заголовок» на всю ширину (1 / -1);
    • одну «главную статью» на 2 столбца и 2 строки (grid-column: span 2; grid-row: span 2;);
    • остальные — обычные на 1 ячейку, чтобы заполнили правую часть.
  • Макет 2 — Bento-сетка: сделай «бенто» — сетку из 5–6 блоков разного размера: один широкий, один высокий, остальные обычные. Это модный стиль, и Grid для него — идеальный.
  • Главное: открой DevTools — на Grid-контейнере есть специальная панель, показывающая линии. Потыкай элементы — увидишь, как они ложатся на сетку.
