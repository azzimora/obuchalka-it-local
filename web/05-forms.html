Формы

как получать данные от пользователя
главная› Web›05
◈ теория

Форма — это способ, которым страница спрашивает у человека что-то: имя, email, выбор, сообщение. Без форм не было бы ни логинов, ни поиска, ни комментариев.

Контейнер — <form>

Всё, что относится к одной форме, лежит внутри <form>:

<form>
  ... поля ...
</form>

У формы есть атрибуты action (куда отправлять) и method (как: get или post), но пока они нам не нужны — вернёмся к ним в JS.

Главные поля

Текстовая строка — <input type="text">:

<input type="text" name="username" placeholder="твоё имя">

Email, пароль, число, дата — тот же input, но с разным type:

  • type="email" — браузер проверит, что там почта;
  • type="password" — символы скрыты точками;
  • type="number" — только цифры;
  • type="date" — календарик;
  • type="color" — выбор цвета;
  • type="checkbox" — галочка;
  • type="radio" — один из нескольких.

Большой текст — <textarea>:

<textarea name="message" rows="4"></textarea>

Выпадающий список — <select> + <option>:

<select name="city">
  <option>Москва</option>
  <option>Питер</option>
</select>

Кнопка — <button>:

<button type="submit">отправить</button>

Подписи — <label>

У каждого поля должна быть подпись. Связывают их так: у поля id, у label — for с тем же значением. Тогда клик по тексту ставит курсор в поле.

<label for="name">Имя:</label>
<input id="name" type="text">

Атрибуты, которые стоит знать

  • placeholder — серая подсказка внутри поля;
  • value — предзаполненное значение;
  • required — поле обязательно;
  • disabled — поле отключено;
  • name — имя поля (важно для отправки и для JS).

Правило: у каждого поля должен быть name, иначе при отправке оно «потеряется».

✦ домашка

Цель: сделать форму регистрации или анкету.

  • Создай файл forms.html с обычным каркасом.
  • Внутри <body> сделай <form> с полями:
    • имя (type="text") — обязательно;
    • email (type="email") — обязательно;
    • пароль (type="password");
    • возраст (type="number");
    • любимый цвет (type="color");
    • согласие с правилами (type="checkbox");
    • пол — два radio: мужской / женский;
    • город — <select> с 3–4 вариантами;
    • о себе — <textarea>;
    • кнопка «отправить».
  • У каждого поля сделай <label> со связкой for/id.
  • Добавь placeholder хотя бы в 3 поля.
  • Проверь required: попробуй отправить форму с пустым обязательным полем — браузер должен поругаться.
  • Эксперимент: убери name у одного поля — визуально ничего не поменяется, но запомни: без name оно не отправится.
