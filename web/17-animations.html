Animations и @keyframes

многошаговые анимации, которые идут сами
главная› Web›17
◈ теория

transition — это переход между двумя состояниями, и ему нужен триггер (:hover, класс). animation — это отдельная история: анимация может идти сама по себе, без всякого наведения, и состоять не из двух, а из скольких угодно шагов.

Два шага

Первое — описать что делать через @keyframes:

@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1); }
}

Второе — сказать элементу использовать эту анимацию:

.heart {
  animation: pulse 1.5s infinite;
}

Всё. Сердечко пульсирует само, без JS и без наведения.

Разбор animation

animation — короткая запись для нескольких свойств:

animation: name duration timing delay iteration direction fill-mode;
  • name — имя из @keyframes;
  • duration — длительность (1s, 500ms);
  • timing — linear, ease, ease-in-out и т.д.;
  • delay — задержка перед стартом;
  • iteration-count — сколько раз: число или infinite;
  • direction — normal, reverse, alternate (туда-сюда);
  • fill-mode — forwards (остаться в конечном состоянии), backwards, both.

Пример полной записи:

.loader {
  animation: spin 2s linear infinite;
}

Крутится вечно, линейно, 2 секунды на оборот.

Шаги в процентах

Можно задавать любое количество шагов:

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-20px); }
}

0%, 100% — то же самое, что from и to.

animation-play-state — пауза

Можно поставить анимацию на паузу через CSS:

.box:hover {
  animation-play-state: paused;
}

Классические анимации

1. Спиннер загрузки:

@keyframes spin {
  to { transform: rotate(360deg); }
}
.loader {
  width: 40px; height: 40px;
  border: 4px solid rgba(255,142,199,0.2);
  border-top-color: #ff8ec7;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}

2. Появление снизу:

@keyframes fadeUp {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.card {
  animation: fadeUp 0.5s ease-out;
}

3. Мягкое покачивание:

@keyframes wiggle {
  0%, 100% { transform: rotate(-3deg); }
  50%      { transform: rotate(3deg); }
}
.icon {
  animation: wiggle 0.6s ease-in-out infinite;
}

4. Пульсирующее свечение:

@keyframes glow {
  0%, 100% { box-shadow: 0 0 8px rgba(255,142,199,0.4); }
  50%      { box-shadow: 0 0 20px rgba(255,142,199,0.9); }
}
.button {
  animation: glow 2s ease-in-out infinite;
}

Задержки по очереди

Чтобы элементы появлялись один за другим, используют animation-delay:

.item:nth-child(1) { animation-delay: 0s; }
.item:nth-child(2) { animation-delay: 0.1s; }
.item:nth-child(3) { animation-delay: 0.2s; }

Так делают «каскадное» появление списка.

Что важно помнить

  • @keyframes описывает, animation применяет;
  • infinite — вечная анимация;
  • alternate — туда-сюда;
  • forwards — остаться в конечном состоянии;
  • Анимируй transform и opacity — они самые плавные;
  • Не злоупотребляй: слишком много анимаций = раздражение.

Accessibility — важное

Некоторым людям анимации мешают или вызывают дискомфорт. Уважай настройку системы:

@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

Это три строки, но они делают сайт дружелюбнее. Запомни этот приём — его спрашивают на собеседованиях.

✦ домашка

Цель: сделать 4 разных анимации и одну составную.

  • Создай файл animations.html + style.css.
  • Упражнение 1 — спиннер: сделай крутящийся круг-загрузчик (бордер сверху другого цвета + rotate 360deg + infinite).
  • Упражнение 2 — появление: сделай карточку, которая при загрузке страницы появляется снизу (fadeUp). Обнови страницу — карточка должна «въезжать».
  • Упражнение 3 — пульс: сделай кружок или сердечко, которое пульсирует через scale.
  • Упражнение 4 — свечение: сделай кнопку, у которой мягко пульсирует box-shadow.
  • Составное: сделай «bounce» — шарик, который прыгает: 0% — внизу, 50% — наверху, 100% — внизу. Добавь alternate или просто два шага.
  • Каскад: сделай список из 5 пунктов, которые появляются по очереди с animation-delay 0.1s / 0.2s / 0.3s…
  • Пауза: повесь на любую анимацию animation-play-state: paused при наведении — анимация встанет на паузу.
  • Главное: добавь в файл блок: 
    @media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
    Это правильная привычка. Не пропускай.
