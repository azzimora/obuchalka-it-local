Каскадность и основные свойства

почему одни стили побеждают другие
главная› Web›07
◈ теория

Слово «каскад» в CSS не случайно. Если на один элемент действуют несколько правил — браузер решает, какое победит, по строгим правилам. Это и есть каскадность.

Три источника стилей

  • Браузерные — то, что браузер ставит по умолчанию (заголовки крупнее, ссылки синие);
  • Авторские — то, что пишешь ты;
  • Пользовательские — то, что может включить сам пользователь (например, тёмную тему).

Твои стили сильнее браузерных. Но пользовательские иногда могут перебить твои — это про доступность.

Приоритет селекторов (специфичность)

Чем «точнее» селектор, тем он сильнее. Порядок такой:

  1. !important — самый сильный (использовать крайне редко!);
  2. inline-стиль прямо в теге (style="...");
  3. селектор по id (#header);
  4. селектор по классу (.card);
  5. селектор по тегу (p).

Пример: если p { color: blue; } и .intro { color: red; } — победит .intro, потому что класс сильнее тега.

Правило последнего

Если два селектора одинаковой силы — побеждает тот, что написан ниже в файле.

p { color: blue; }
p { color: red; }  /* победит это, потому что ниже */

Наследование

Некоторые свойства передаются от родителя к ребёнку. Например, если задать цвет всему body — текст внутри тоже станет таким, если у него не задан свой цвет.

body { color: #f3e8f5; font-family: 'Segoe UI', sans-serif; }

Наследуются: color, font-family, font-size, line-height. Не наследуются: margin, padding, border.

Единицы измерения

  • px — пиксели, абсолютно;
  • % — относительно родителя;
  • rem — относительно размера шрифта в html (обычно 16px). Удобно для масштабируемости;
  • em — относительно размера шрифта родителя;
  • vw / vh — процент от ширины / высоты окна.

Полезные свойства «на каждый день»

  • border-radius — скругление углов;
  • box-shadow — тень у блока;
  • opacity — прозрачность (0–1);
  • text-decoration — подчёркивание (или убрать none);
  • line-height — межстрочный интервал;
  • letter-spacing — расстояние между буквами.

Как проверить, почему стиль не работает

  1. Открой страницу и нажми F12 — откроются DevTools.
  2. Выбери элемент «стрелкой» в углу панели.
  3. Справа увидишь все стили, которые на него действуют.
  4. Зачёркнутые — проиграли каскаду. Так ты найдёшь, кто кого перебил.

Это самый полезный навык в CSS. Не угадывать, а подсматривать у браузера.

✦ домашка

Цель: увидеть каскад своими глазами и научиться пользоваться DevTools.

  • Создай файл cascade.html + style.css.
  • В HTML сделай:
    • абзац <p class="intro">;
    • блок <div id="hero"></div>.
  • В CSS сделай так, чтобы проверить каскад:
    • напиши p { color: blue; };
    • ниже напиши .intro { color: red; } — убедись, что победил красный;
    • ещё ниже напиши p.intro { color: green; } — убедись, что теперь зелёный (потому что селектор точнее);
    • напиши #hero { color: gold; } — проверь, что id побеждает всё.
  • Эксперимент с наследованием: задай body { color: #333; font-family: Georgia; } — посмотри, как всё на странице подхватило это.
  • Поставь блоку #hero:
    • padding: 40px;
    • border-radius: 20px;
    • box-shadow: 0 10px 30px rgba(0,0,0,0.3);
    • любой фон.
  • Главное задание: открой DevTools (F12), выбери любой элемент, найди какое-нибудь зачёркнутое свойство и разберись, почему оно проиграло. Запиши вывод в конспект.
