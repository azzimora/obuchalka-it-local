Стилизация таблиц

border-collapse, зебры и адаптив
главная› Web›15
◈ теория

Таблицы в HTML бывают двух видов: таблицы данных (расписание, цены, статистика) — и таблицы для вёрстки, которыми пользовались в 2005. Второе — зло, для вёрстки есть Grid и Flexbox. А вот первые — полезны и требуют стилизации.

Структура таблицы

<table>
  <thead>
    <tr>
      <th>Имя</th>
      <th>Возраст</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Аня</td>
      <td>17</td>
    </tr>
  </tbody>
</table>
  • <table> — сама таблица;
  • <thead> — шапка;
  • <tbody> — тело;
  • <tr> — строка (table row);
  • <th> — ячейка-заголовок (жирная, по центру);
  • <td> — обычная ячейка (table data).

border-collapse — обязательно

По умолчанию у каждой ячейки своя рамка, и между ними пустота. Убирается одной строкой:

table {
  border-collapse: collapse;
  width: 100%;
}

Теперь рамки «склеиваются» и выглядят как единая сетка.

Базовый стиль таблицы

table {
  width: 100%;
  border-collapse: collapse;
  font-size: 0.95rem;
}
th, td {
  padding: 12px 16px;
  text-align: left;
  border-bottom: 1px solid rgba(255,142,199,0.15);
}
th {
  background: rgba(255,142,199,0.08);
  color: #ffb8d9;
  font-weight: 600;
  text-transform: uppercase;
  font-size: 0.8rem;
  letter-spacing: 1px;
}
tr:hover {
  background: rgba(255,142,199,0.05);
}

Зебра (zebra striping)

Чередование фона строк помогает читать большие таблицы:

tbody tr:nth-child(even) {
  background: rgba(255,255,255,0.03);
}

:nth-child(even) — каждый чётный. Можно odd — каждый нечётный. Можно формулу: nth-child(3n) — каждый третий.

Скруглённые углы у таблицы

Напрямую border-radius у <table> не сработает, если у ячеек есть фон. Трюк — обернуть в контейнер:

.table-wrap {
  border-radius: 12px;
  overflow: hidden;
  border: 1px solid rgba(255,142,199,0.15);
}

Адаптив — самое важное

Таблицы плохо работают на телефонах: они шире экрана. Два подхода:

1. Горизонтальный скролл (простой и рабочий):

.table-wrap {
  overflow-x: auto;
}

На узком экране таблица скроллится вбок, но не ломается.

2. Перестройка в карточки (сложнее, но красивее): через media-запрос каждой строке дают display: block; и ячейкам рисуют подписи из data-label. Это уже тема 18, пока достаточно первого способа.

Выравнивание

  • Числа — по правому краю (text-align: right), так их легче сравнивать;
  • Текст — по левому;
  • Заголовки — по тому же краю, что и данные под ними.

Полезные мелочи

  • table-layout: fixed; — ширина столбцов по первой строке, работает быстрее;
  • caption — подпись таблицы, ставится сразу после <table>;
  • colspan и rowspan — объединение ячеек по горизонтали и вертикали.

Что важно запомнить

  • border-collapse: collapse; — обязательно;
  • nth-child(even) — для зебры;
  • Обёртка с overflow-x: auto — спасение на телефоне;
  • Таблицы только для данных, не для вёрстки.
✦ домашка

Цель: сделать красивую таблицу данных, которая работает и на телефоне.

  • Создай файл tables.html + style.css.
  • Сделай таблицу с <thead> и <tbody>, минимум 5 строк. Например, «Мои любимые фильмы»: название, год, режиссёр, оценка.
  • Примени:
    • border-collapse: collapse; — сразу;
    • width: 100%;;
    • padding у th и td;
    • стиль th: фон, цвет, uppercase;
    • рамку снизу у ячеек.
  • Добавь зебру: tbody tr:nth-child(even) { background: ...; }.
  • Добавь tr:hover — при наведении строка подсвечивается.
  • Оберни таблицу в <div class="table-wrap"> с:
    • border-radius — скругление;
    • overflow: hidden — чтобы углы срезались;
    • overflow-x: auto — для скролла на узких экранах.
  • Числовые столбцы (год, оценка) выровняй по правому краю.
  • Проверка адаптива: сузь окно до ширины телефона — таблица должна скроллиться вбок, а не вылезать за экран.
  • Главное: сделай вторую таблицу с colspan или rowspan — например, «Расписание на неделю», где «Выходные» объединяют две строки. Это научит думать о структуре.
