Списки

как хранить много значений в одном месте
главная› Python›10
◈ теория

Переменная хранит одно значение. А если нужно хранить сто? Список дел, оценки, имена, числа. Для этого в Python есть списки.

Что такое список

Список — упорядоченная коллекция значений. Пишется в квадратных скобках, элементы через запятую.

fruits = ["яблоко", "груша", "слива"]
numbers = [1, 2, 3, 4, 5]
mixed = ["Аня", 17, 1.65, True]

В списке могут быть любые типы. Даже другие списки — тогда это «список списков».

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

Индексы

Как и в строках: нумерация с 0, с конца — с −1.

fruits = ["яблоко", "груша", "слива"]

print(fruits[0])    # яблоко
print(fruits[1])    # груша
print(fruits[-1])   # слива
print(fruits[-2])   # груша

В отличие от строк, список можно менять:

fruits[1] = "банан"
print(fruits)   # ["яблоко", "банан", "слива"]

Срезы

Работают так же, как у строк:

nums = [10, 20, 30, 40, 50]

print(nums[1:4])    # [20, 30, 40]
print(nums[:2])     # [10, 20]
print(nums[2:])     # [30, 40, 50]
print(nums[::-1])   # [50, 40, 30, 20, 10] — наоборот

len — длина списка

nums = [1, 2, 3, 4, 5]
print(len(nums))   # 5

Основные методы

append(x) — добавить в конец:

fruits = ["яблоко"]
fruits.append("груша")
print(fruits)   # ["яблоко", "груша"]

insert(i, x) — вставить по индексу:

fruits.insert(1, "банан")
print(fruits)   # ["яблоко", "банан", "груша"]

remove(x) — удалить первое вхождение:

fruits.remove("банан")
print(fruits)   # ["яблоко", "груша"]

pop(i) — удалить по индексу и вернуть значение:

last = fruits.pop()    # удаляет последний
first = fruits.pop(0)  # удаляет первый
print(last, first)

clear() — очистить список:

fruits.clear()
print(fruits)   # []

index(x) — индекс элемента:

nums = [10, 20, 30]
print(nums.index(20))   # 1

count(x) — сколько раз встречается:

nums = [1, 2, 2, 3, 2]
print(nums.count(2))   # 3

sort() — сортировка:

nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums.sort()
print(nums)   # [1, 1, 2, 3, 4, 5, 6, 9]

reverse() — перевернуть:

nums.reverse()
print(nums)   # [9, 6, 5, 4, 3, 2, 1, 1]

Проверка на наличие

fruits = ["яблоко", "груша"]

print("яблоко" in fruits)   # True
print("банан" in fruits)    # False
print("банан" not in fruits)  # True

Сложение и умножение

a = [1, 2]
b = [3, 4]

print(a + b)      # [1, 2, 3, 4]
print(a * 3)      # [1, 2, 1, 2, 1, 2]

Перебор списка

Самый частый способ:

fruits = ["яблоко", "груша", "слива"]

for fruit in fruits:
    print(fruit)

С индексами:

for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

С enumerate — короче:

for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

Списковые включения (list comprehension)

Короткий способ создать список на основе другого:

nums = [1, 2, 3, 4, 5]

# обычный способ
squares = []
for n in nums:
    squares.append(n ** 2)

# list comprehension
squares = [n ** 2 for n in nums]
print(squares)   # [1, 4, 9, 16, 25]

С условием:

nums = [1, 2, 3, 4, 5, 6]
evens = [n for n in nums if n % 2 == 0]
print(evens)   # [2, 4, 6]

Это очень удобный инструмент. Дальше ты будешь использовать его постоянно.

Полезные функции

nums = [3, 1, 4, 1, 5]

print(sum(nums))   # 14 — сумма
print(max(nums))   # 5 — максимум
print(min(nums))   # 1 — минимум
print(sorted(nums))   # [1, 1, 3, 4, 5] — новая сортированная копия

Важно: sort() меняет сам список, а sorted() возвращает новый. Это разные вещи.

Копирование списка

Тут есть ловушка. Если написать b = a — это не копия, это «второе имя» того же списка. Изменишь b — изменится a.

a = [1, 2, 3]
b = a
b.append(4)
print(a)   # [1, 2, 3, 4] — a тоже изменился!

Правильная копия:

a = [1, 2, 3]
b = a.copy()
b.append(4)
print(a)   # [1, 2, 3] — не изменилось
print(b)   # [1, 2, 3, 4]

Пример: список дел

tasks = []

while True:
    action = input("add / show / quit: ")

    if action == "add":
        task = input("Задача: ")
        tasks.append(task)
        print("Добавлено")
    elif action == "show":
        for i, task in enumerate(tasks, 1):
            print(f"{i}. {task}")
    elif action == "quit":
        break

Главное из темы

  • Список — коллекция значений в [].
  • Индексы с 0, с конца с −1.
  • Список можно менять: lst[0] = "...".
  • Методы: append, insert, remove, pop, sort, reverse.
  • in — проверка наличия.
  • len, sum, max, min, sorted — встроенные функции.
  • List comprehension — короткий способ создать список.
  • b = a.copy() — копия. b = a — не копия.
