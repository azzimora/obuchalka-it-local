Условный оператор if

как заставить программу выбирать
главная› Python›06
◈ теория

До этого программы шли по прямой: строка за строкой, без вариантов. Но настоящая программа должна принимать решения: если одно — делать так, если другое — иначе. Для этого есть оператор if.

Простейший if

age = 17

if age >= 18:
    print("совершеннолетний")

Что здесь:

  • if — «если»;
  • age >= 18 — условие. Истинно или ложно;
  • : — двоеточие в конце. Обязательно!
  • строка с отступом — что делать, если условие истинно.

Отступ важен. В Python код, который «внутри if», пишется с отступом (4 пробела или Tab). Без отступа Python не поймёт, что это часть условия.

if / else

Если условие ложно — что делать? Для этого есть else.

age = 15

if age >= 18:
    print("совершеннолетний")
else:
    print("несовершеннолетний")

Работает так: если условие истинно — первая ветка, если ложно — вторая. Одно из двух обязательно выполнится.

if / elif / else

Если вариантов больше двух — есть elif (сокращение от else if).

age = 15

if age >= 18:
    print("взрослый")
elif age >= 14:
    print("подросток")
elif age >= 7:
    print("школьник")
else:
    print("маленький")

Python проверяет условия сверху вниз. Как только одно стало истинным — заходит в него и выходит из всей конструкции. Остальные не проверяет.

Совет: самое строгое условие — вверх, самое широкое — вниз.

Операторы сравнения

  • == — равно (два знака!)
  • != — не равно
  • > — больше
  • < — меньше
  • >= — больше или равно
  • <= — меньше или равно

Осторожно: = — это присваивание. == — сравнение. Это разные вещи.

x = 5      # положили 5 в x
x == 5     # проверили: x равен 5?

Логические операторы

Условия можно соединять:

  • and — «и». Истинно, если оба условия истинны;
  • or — «или». Истинно, если хотя бы одно истинно;
  • not — «не». Меняет истину на ложь и наоборот.
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("можно пройти")

if age < 7 or age > 65:
    print("льготный билет")

if not has_ticket:
    print("нужен билет")

Вложенные условия

Внутри одного if может быть другой if:

age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("проходите")
    else:
        print("купите билет")
else:
    print("до 18 вход запрещён")

Совет: если вложенность глубже двух уровней — лучше использовать and вместо вложенных if.

if age >= 18 and has_ticket:
    print("проходите")

Что считается истиной

В Python не только True и False могут быть условием. Есть «ложные» значения:

  • False, None;
  • число 0;
  • пустая строка "";
  • пустой список [].

Всё остальное — истина. Это удобно:

name = input("Имя: ")

if name:
    print(f"Привет, {name}!")
else:
    print("Ты не ввёл имя")

Если пользователь оставит поле пустым — name будет "", условие ложно, выведется второе сообщение.

Проверка на несколько значений

Можно проверять, входит ли значение в список:

color = input("Цвет: ")

if color in ["красный", "синий", "зелёный"]:
    print("основной цвет")
else:
    print("другой")

Пример программы: калькулятор оценок

score = int(input("Сколько баллов? "))

if score >= 90:
    print("5")
elif score >= 75:
    print("4")
elif score >= 60:
    print("3")
else:
    print("2")

Правила оформления

  • После if, elif, else — двоеточие.
  • Тело условия — с отступом (обычно 4 пробела).
  • Один уровень вложенности — один отступ.
  • Если внутри только одна строка — всё равно с новой строки и с отступом. Писать if x: print("да") можно, но не принято.

Главное из темы

  • if — проверяет условие. Если истинно — выполняет код с отступом.
  • else — что делать иначе.
  • elif — дополнительные варианты.
  • Сравнение — через ==, !=, >, <, >=, <=.
  • Логика — через and, or, not.
  • После условий — двоеточие, внутри — отступ.
  • Пустая строка, 0, пустой список — «ложь».

    • «конвертер оценок» — 5, 4, 3, 2 → словами;
    • «тест на возраст» — что можно и что нельзя в разном возрасте.
