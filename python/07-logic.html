Логические операторы

and, or, not — и как думать условиями
главная› Python›07
◈ теория

В прошлой теме мы познакомились с if. Но часто условие — это не одно сравнение, а несколько: «если возраст больше 18 и есть билет», «если оценка 5 или 4», «если не дождь». Для этого есть логические операторы.

Три оператора

  • and — «и». Истинно, только если оба условия истинны;
  • or — «или». Истинно, если хотя бы одно истинно;
  • not — «не». Переворачивает: истина → ложь, ложь → истина.

and

age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("можно войти")

Здесь проверяются оба условия. Если хотя бы одно ложно — весь and ложен.

Таблица истинности:

A B A and B
TrueTrueTrue
TrueFalseFalse
FalseTrueFalse
FalseFalseFalse

or

day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("выходной")

Здесь достаточно, чтобы одно из условий было истинным.

A B A or B
TrueTrueTrue
TrueFalseTrue
FalseTrueTrue
FalseFalseFalse

not

is_raining = False

if not is_raining:
    print("можно гулять")

not is_raining означает «если не идёт дождь». То есть если is_raining ложно — условие истинно.

A not A
TrueFalse
FalseTrue

Комбинирование

Операторы можно соединять. Но следи за скобками — они определяют порядок.

age = 25
is_student = True
has_discount_card = False

if (age < 18 or is_student) and not has_discount_card:
    print("положена скидка")

Читается так: «если (моложе 18 или студент) и при этом нет карты скидок».

Без скобок Python выполняет not первым, потом and, потом or. Это как математика: умножение раньше сложения. Но лучше всегда ставить скобки — для себя и для читателя.

Порядок выполнения

  1. not — первым;
  2. and — вторым;
  3. or — последним.

Пример:

a or b and not c

Читается как:

a or (b and (not c))

Короткое замыкание

Python ленивый. Если результат уже ясен — он не проверяет остальное.

  • В a and b: если a ложно — b не проверяется, потому что результат уже False.
  • В a or b: если a истинно — b не проверяется, потому что результат уже True.

Это полезно, когда правая часть может вызвать ошибку:

if user != None and user.name == "Аня":
    print("привет, Аня")

Если user — None, вторая часть не выполнится, и не будет ошибки. Без and Python бы попытался прочитать user.name у пустого объекта — и упал.

Проверка «в диапазоне»

В Python можно писать цепочки сравнений:

age = 25

if 18 <= age <= 65:
    print("рабочий возраст")

Это то же самое, что:

if age >= 18 and age <= 65:

Но короче и читается лучше.

Проверка «в списке»

Вместо длинного or используй in:

# плохо
if day == "сб" or day == "вс" or day == "пт":
    print("отдых")

# хорошо
if day in ["сб", "вс", "пт"]:
    print("отдых")

Проверка «не в списке»

if name not in ["Аня", "Макс", "Лена"]:
    print("новенький")

Логические значения как переменные

Условие можно сохранить в переменную — она будет True или False:

age = 20
has_ticket = True

can_enter = age >= 18 and has_ticket

if can_enter:
    print("проходите")

Это удобно, когда условие длинное, а использовать его нужно несколько раз. Имя переменной объясняет смысл.

Пример: проверка данных

name = input("Имя: ")
age = int(input("Возраст: "))

if not name:
    print("Имя не введено")
elif age < 0 or age > 150:
    print("Возраст неправдоподобный")
elif age < 18:
    print(f"{name}, ты ещё несовершеннолетний")
else:
    print(f"{name}, добро пожаловать!")

Пример: калькулятор скидки

age = int(input("Возраст: "))
is_student = input("Студент? (да/нет): ") == "да"

if age < 7 or age > 65 or is_student:
    print("скидка 50%")
elif age < 18:
    print("скидка 20%")
else:
    print("без скидки")

Главное из темы

  • and — истинно, если оба условия истинны.
  • or — истинно, если хотя бы одно истинно.
  • not — переворачивает.
  • Порядок: not → and → or. Скобки — для ясности.
  • Короткое замыкание: Python не проверяет то, что уже не влияет на результат.
  • 18 <= x <= 65 — можно объединять сравнения.
  • in — проверка «в списке», короче чем длинный or.
  • Условие можно сохранить в переменную.

  • Задание 2 — or. Спроси день недели. Если суббота или воскресенье — «выходной», иначе — «рабочий день».
  • Задание 3 — not. Спроси, идёт ли дождь (да/нет). Если не идёт — «можно гулять», иначе — «возьми зонт».
  • Задание 4 — комбинированное. Спроси возраст и студент ли пользователь. Если возраст меньше 18 или студент — «скидка», иначе — «без скидки».
  • Задание 5 — диапазон. Спроси число. Проверь, входит ли оно в диапазон от 1 до 100. Используй цепочку 1 <= x <= 100.
  • Задание 6 — в списке. Спроси любимый цвет. Если он в списке ["красный", "синий", "зелёный"] — «основной», иначе — «другой».
  • Задание 7 — билет. Спроси возраст и наличие билета. Правила:
    • возраст ≥ 18 и билет есть → «проходите»;
    • возраст ≥ 18 и билета нет → «купите билет»;
    • возраст < 18 и есть взрослый → «проходите со взрослым»;
    • возраст < 18 и без взрослого → «нельзя».
  • Задание 8 — сохранённое условие. Спроси три числа. Проверь, все ли они положительные. Сохрани условие в переменную all_positive. Потом выведи результат.
  • Задание 9 — своя программа. Придумай что-то своё, где нужны сложные условия. Идеи:
    • «тест на скидку в магазине» — возраст, сумма покупки, карта лояльности;
    • «доступ к игре» — возраст, возраст родителей разрешил, куплена ли игра;
    • «погода» — температура и влажность, выдать совет.
