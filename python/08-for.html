Цикл for

повторять код без копирования
главная› Python›08
◈ теория

Представь, что нужно вывести числа от 1 до 100. Писать 100 строк print? Нет. Для повторяющихся действий есть циклы. for — самый частый.

Что такое цикл

Цикл — это способ повторить один и тот же код много раз, не копируя его. Один раз написал — Python выполнил десять, сто, миллион раз.

for с range()

Функция range() создаёт последовательность чисел. А for проходит по ней.

for i in range(5):
    print(i)

Вывод:

0
1
2
3
4

Что здесь:

  • for — «для каждого»;
  • i — переменная цикла. В неё попадает каждое значение из последовательности;
  • in range(5) — по чему проходим. range(5) — числа 0, 1, 2, 3, 4;
  • : — двоеточие;
  • тело цикла — с отступом.

Обрати внимание: range(5) даёт числа от 0 до 4, а не от 1 до 5. Нумерация с нуля, как и у индексов.

range — три варианта

range(5)          # 0, 1, 2, 3, 4
range(2, 7)       # 2, 3, 4, 5, 6
range(0, 10, 2)   # 0, 2, 4, 6, 8
  • range(конец) — от 0 до конца (не включая);
  • range(начало, конец) — от начала до конца (не включая);
  • range(начало, конец, шаг) — с шагом.

Если нужно от 1 до 10 включительно — range(1, 11).

Примеры

Вывести квадраты чисел от 1 до 5:

for i in range(1, 6):
    print(f"{i} в квадрате = {i ** 2}")

Сумма чисел от 1 до 100:

total = 0

for i in range(1, 101):
    total = total + i

print(f"Сумма: {total}")

Обратный отсчёт:

for i in range(10, 0, -1):
    print(i)

print("Пуск!")

for по строке

for может проходить не только по числам, но и по символам строки:

word = "Python"

for letter in word:
    print(letter)

Вывод:

P
y
t
h
o
n

for по списку

fruits = ["яблоко", "груша", "слива"]

for fruit in fruits:
    print(f"Я люблю {fruit}")

enumerate — счётчик в цикле

Если нужно не только значение, но и его номер:

fruits = ["яблоко", "груша", "слива"]

for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

Вывод:

0: яблоко
1: груша
2: слива

Если хочешь нумерацию с 1 — enumerate(fruits, 1).

break и continue

break — выйти из цикла досрочно:

for i in range(1, 100):
    print(i)
    if i == 5:
        break

Выведет 1, 2, 3, 4, 5 и остановится.

continue — пропустить текущую итерацию, перейти к следующей:

for i in range(1, 11):
    if i % 2 == 0:
        continue
    print(i)   # выведет только нечётные: 1, 3, 5, 7, 9

Вложенные циклы

Один цикл внутри другого. Например, таблица умножения:

for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i} × {j} = {i * j}")
    print()   # пустая строка между блоками

Внешний цикл идёт 3 раза. Внутри каждого — внутренний тоже 3 раза. Итого 9 строк.

Типичные задачи

Подсчёт:

count = 0

for i in range(1, 101):
    if i % 3 == 0:
        count = count + 1

print(f"Чисел, делящихся на 3: {count}")

Поиск максимума:

numbers = [3, 7, 2, 9, 4, 1]
max_num = numbers[0]

for n in numbers:
    if n > max_num:
        max_num = n

print(f"Максимум: {max_num}")

Накопление строки:

result = ""

for i in range(1, 6):
    result = result + str(i) + " "

print(result)   # "1 2 3 4 5 "

Как не попасть в бесконечный цикл

Цикл for всегда идёт по конкретной последовательности — он не может быть бесконечным. Бесконечными бывают только while (о них в следующей теме).

Но можно случайно написать цикл, который идёт дольше, чем нужно — например, range(1000000). Если запустишь — программа будет долго работать. Это нормально, просто нажми Ctrl+C в терминале, чтобы остановить.

Главное из темы

  • for — цикл для повторения кода.
  • range(n) — числа от 0 до n−1.
  • range(a, b) — от a до b−1.
  • range(a, b, step) — с шагом.
  • for может идти по строке, списку, чему угодно.
  • enumerate — с номером итерации.
  • break — выйти из цикла, continue — пропустить итерацию.
  • Циклы можно вкладывать.
  • Тело цикла — с отступом, как у if.
