Первая программа и вывод данных

функция print, строки и комментарии

◈ теория

В первой теме ты уже запустила программу hello.py. Теперь разберёмся, как это работает и что ещё умеет print.

Что такое функция

Функция — это готовая команда, которая что-то делает. Она есть в Python «из коробки», писать её самой не надо. Ты просто вызываешь её по имени и даёшь данные.

print — одна из самых простых функций. Она берёт то, что ты ей дала, и выводит на экран.

print("Привет, мир!")
  • print — имя функции;
  • ( и ) — скобки. Внутри них — то, что нужно вывести;
  • "Привет, мир!" — строка. Текст в кавычках.

Строки и кавычки

Строка — это текст. В Python строки пишут в кавычках. Можно в двойных "...", можно в одинарных '...' — разницы нет.

print("Привет")
print('Привет')

Оба варианта работают одинаково. Главное — чтобы кавычки были парные: открывающая и закрывающая одинаковые.

Если открыть двойную, а закрыть одинарную — будет ошибка.

Несколько строк

Каждый print выводит текст с новой строки. Хочешь несколько строк — пиши несколько print:

print("Привет!")
print("Меня зовут Аня.")
print("Я учу Python.")

Вывод:

Привет!
Меня зовут Аня.
Я учу Python.

Вывод чисел

Числа пишут без кавычек. Кавычки — только для текста.

print(42)
print(3.14)
print(2 + 3)

Вывод:

42
3.14
5

В третьем случае Python сначала посчитал 2 + 3, а потом вывел результат.

Что будет, если перепутать

Число в кавычках — это строка, а не число:

print("2 + 3")   # выведет: 2 + 3 (как текст)
print(2 + 3)     # выведет: 5 (как результат)

Разница видна сразу. Кавычки говорят Python: «это текст, не считай».

Комментарии

Комментарий — это текст в коде, который Python игнорирует. Нужен для заметок: что делает код, зачем, что поменять потом.

В Python комментарий начинается с символа #. Всё после него до конца строки — игнорируется.

# это комментарий, Python его не видит

print("Привет")  # а это — код, он выполнится

Комментарии полезны, когда:

  • хочешь оставить заметку себе на будущее;
  • временно «выключить» строку кода — поставить # в начале, и она не выполнится;
  • объяснить сложное место другим (или себе через месяц).

Пробелы и отступы

Python очень чувствителен к отступам. В отличие от других языков, где отступы — просто для красоты, здесь они — часть синтаксиса.

Пока мы пишем код без блоков (без условий и циклов), отступы в начале строки не нужны. Каждая команда — с новой строки, без пробелов впереди.

print("раз")
print("два")
print("три")

Если случайно поставить пробел в начале — Python может выдать ошибку IndentationError. Так что следи за этим.

Пустая строка

Иногда нужно вывести пустую строку — просто отступ. Для этого:

print()

Или:

print("")

Оба варианта дают пустую строку на экране.

Как выглядит типичная программа

# моя первая программа
# изучаю Python

print("Привет!")
print()
print("Сегодня я узнала:")
print("- что такое print")
print("- как писать строки")
print("- зачем нужны комментарии")

print("Готово!")

Вот и всё. Пока — просто текст на экране. Дальше научимся принимать данные от пользователя, считать, повторять.

Главное из темы

  • print() — функция, которая выводит на экран.
  • Строки — в кавычках (любых, но парных).
  • Числа — без кавычек.
  • Каждый print — с новой строки.
  • Комментарий — # в начале строки, Python его игнорирует.
  • Отступы в начале строки — важны, пока их лучше не ставить.
  • print() без аргументов — пустая строка.
