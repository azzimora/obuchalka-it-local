Цикл while

повторять, пока условие истинно
главная› Python›09
◈ теория

for хорош, когда известно, сколько раз повторять. А если неизвестно? Например, «повторяй, пока пользователь не введёт правильный пароль». Тут нужен while.

Что такое while

while повторяет код, пока условие истинно. Как только станет ложно — выходит.

i = 0

while i < 5:
    print(i)
    i = i + 1

Вывод:

0
1
2
3
4

Что здесь:

  • while i < 5: — «пока i меньше 5»;
  • внутри — вывод и увеличение i;
  • когда i станет 5 — условие ложно, цикл останавливается.

Важно: внутри цикла должно быть что-то, что меняет условие. Иначе цикл будет бесконечным.

for vs while — когда что

  • for — когда знаешь, сколько раз. «Выведи 10 чисел». «Пройди по списку».
  • while — когда не знаешь, сколько раз. «Пока не угадает число». «Пока не введёт пароль».

Бесконечный цикл

Если условие всегда истинно — цикл никогда не остановится:

while True:
    print("это никогда не кончится")

Такой код будет выводить строку бесконечно, пока ты не остановишь его (Ctrl+C в терминале).

Иногда бесконечный цикл — это нормально. Например, «игра идёт, пока пользователь не выйдет». Тогда выход делают через break.

break — выход из цикла

Самый частый приём: бесконечный цикл + выход по условию.

while True:
    answer = input("Скажи 'выход' чтобы закончить: ")
    if answer == "выход":
        break
    print(f"Ты сказал: {answer}")

print("Пока!")

Здесь цикл крутится, пока пользователь не введёт «выход». Тогда break выкидывает нас из цикла.

continue — пропустить итерацию

i = 0

while i < 10:
    i = i + 1
    if i % 2 == 0:
        continue
    print(i)   # выведет: 1, 3, 5, 7, 9

Классический пример: угадай число

secret = 7
guess = 0
tries = 0

while guess != secret:
    guess = int(input("Угадай число от 1 до 10: "))
    tries = tries + 1

    if guess < secret:
        print("Больше")
    elif guess > secret:
        print("Меньше")

print(f"Угадал! Попыток: {tries}")

Программа спрашивает, пока пользователь не угадает. Сколько раз — заранее неизвестно. Поэтому while.

Пример: проверка пароля

password = "python123"
attempt = ""

while attempt != password:
    attempt = input("Пароль: ")
    if attempt != password:
        print("Неверно, попробуй снова")

print("Доступ разрешён!")

while с else

У while есть необычная особенность: можно добавить else. Он срабатывает, если цикл завершился естественно (не через break).

i = 0

while i < 3:
    print(i)
    i = i + 1
else:
    print("Цикл завершён")

Если бы внутри был break — else бы не выполнился. На практике используется редко, но полезно знать.

Вложенные while

Как и for, можно вкладывать. Например, таблица умножения:

i = 1

while i <= 3:
    j = 1
    while j <= 3:
        print(f"{i} × {j} = {i * j}")
        j = j + 1
    print()
    i = i + 1

Осторожно: если забыть увеличить j — внутренний цикл станет бесконечным, и внешний никогда не пойдёт дальше.

Типичные ошибки

1. Забыть изменить переменную.

i = 0
while i < 5:
    print(i)   # забыли i = i + 1 — бесконечный цикл

2. Изменить не ту переменную.

x = 0
while x < 5:
    y = y + 1   # а условие про x — тоже бесконечно

3. Условие никогда не станет ложным.

i = 0
while i != 10:
    i = i + 2   # i станет 10? Нет: 0, 2, 4, 6, 8, 10 — станет. Но если шаг 3 — проскочит мимо.

Совет: перед запуском while мысленно проверь: «условие точно когда-то станет ложным?»

Главное из темы

  • while повторяет код, пока условие истинно.
  • Внутри должно быть что-то, что меняет условие.
  • while True — бесконечный цикл. Выход через break.
  • break — выйти, continue — пропустить итерацию.
  • for — когда известно, сколько раз; while — когда неизвестно.
  • У while есть else — срабатывает, если не было break.
  • Циклы можно вкладывать, но следи за переменными.
