Словари

данные с именованными ключами
главная› Python›11
◈ теория

Список удобен, когда данные идут по порядку: первый, второй, третий. Но что если нужно хранить именованные данные? Например, «имя: Аня, возраст: 17, город: Москва». Для этого есть словари.

Что такое словарь

Словарь — коллекция пар «ключ → значение». Пишется в фигурных скобках.

person = {
    "name": "Аня",
    "age": 17,
    "city": "Москва"
}

В отличие от списка, где доступ по индексу (0, 1, 2), в словаре доступ по ключу.

print(person["name"])   # Аня
print(person["age"])    # 17

Ключи и значения

  • Ключ — обычно строка или число. Должен быть уникальным;
  • Значение — что угодно: строка, число, список, другой словарь.
user = {
    "name": "Аня",
    "age": 17,
    "hobbies": ["чтение", "рисование"],
    "address": {
        "city": "Москва",
        "street": "Ленина"
    }
}

Доступ и изменение

person = {"name": "Аня", "age": 17}

# прочитать
print(person["name"])

# изменить
person["age"] = 18
print(person["age"])   # 18

# добавить новое
person["city"] = "Москва"
print(person)

Безопасный доступ: get()

Если ключа нет — обычный доступ вызовет ошибку:

print(person["salary"])   # KeyError

Чтобы этого избежать, используют get():

print(person.get("salary"))         # None
print(person.get("salary", 0))      # 0 — значение по умолчанию

Совет: если не уверен, что ключ есть — используй get().

Удаление

person = {"name": "Аня", "age": 17, "city": "Москва"}

del person["city"]
print(person)   # {"name": "Аня", "age": 17}

# или через pop — возвращает значение
age = person.pop("age")
print(age)      # 17
print(person)   # {"name": "Аня"}

Проверка наличия ключа

person = {"name": "Аня", "age": 17}

print("name" in person)      # True
print("salary" in person)    # False
print("salary" not in person)  # True

Перебор словаря

Только ключи:

person = {"name": "Аня", "age": 17}

for key in person:
    print(key)

Вывод:

name
age

Только значения:

for value in person.values():
    print(value)

Пары ключ-значение:

for key, value in person.items():
    print(f"{key}: {value}")

Вывод:

name: Аня
age: 17

Совет: items() используется чаще всего.

Длина словаря

person = {"name": "Аня", "age": 17}
print(len(person))   # 2

Полезные методы

keys() — все ключи:

print(list(person.keys()))   # ["name", "age"]

values() — все значения:

print(list(person.values()))  # ["Аня", 17]

items() — все пары:

print(list(person.items()))  # [("name", "Аня"), ("age", 17)]

update() — добавить или обновить сразу несколько:

person.update({"city": "Москва", "age": 18})
print(person)

clear() — очистить:

person.clear()
print(person)   # {}

Когда использовать словарь, а когда список

  • Список — когда важен порядок. Оценки по предметам, шаги рецепта, список задач.
  • Словарь — когда важен смысл. Характеристики объекта (имя, возраст), настройки, статистика.

Иногда их комбинируют. Например, список словарей:

users = [
    {"name": "Аня", "age": 17},
    {"name": "Макс", "age": 18},
    {"name": "Лена", "age": 16}
]

for user in users:
    print(f"{user['name']}, {user['age']} лет")

Это очень частый формат данных. Например, так приходят данные из API.

Пример: телефонная книга

contacts = {
    "Аня": "+7-900-111-22-33",
    "Макс": "+7-900-444-55-66"
}

name = input("Кого искать? ")

if name in contacts:
    print(f"{name}: {contacts[name]}")
else:
    print("Не найден")

Пример: счётчик слов

text = "я учу python и python это круто"
words = text.split()

counts = {}

for word in words:
    if word in counts:
        counts[word] = counts[word] + 1
    else:
        counts[word] = 1

for word, count in counts.items():
    print(f"{word}: {count}")

Такой подсчёт — классическая задача. Используется и в чат-ботах, и в анализе текста.

Главное из темы

  • Словарь — пары «ключ → значение» в {}.
  • Доступ по ключу: d["key"].
  • get() — безопасный доступ, если ключа может не быть.
  • in — проверка ключа.
  • items() — перебор пар в цикле.
  • update(), pop(), clear() — методы.
  • Список словарей — частый формат данных.
