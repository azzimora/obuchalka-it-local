Контрольные проекты

собрать всё, что было, в настоящие программы

◈ теория

Это финальная тема курса. Здесь нет новой теории — только практика. Ты соберёшь всё, что выучила, в несколько настоящих программ.

Что уже есть в арсенале:

  • переменные, типы, f-строки;
  • input и print;
  • условия if / elif / else;
  • логика and / or / not;
  • циклы for и while;
  • списки и словари;
  • функции;
  • модули random и math.

Этого достаточно, чтобы делать полноценные консольные программы.

Что такое «контрольный проект»

Это не «упражнение на одну строчку». Это законченная программа, у которой есть:

  • цель — что она делает;
  • пользователь — кто ей пользуется;
  • структура — меню, действия, выход;
  • логика — функции, списки, словари, условия, циклы;
  • обработка ошибок — что если пользователь введёт не то.

Так выглядит настоящая программа. Не «сделай что-то», а «сделай инструмент, которым можно пользоваться».

Как строить проект

Порядок такой:

  1. Идея. Что делает программа, для кого. Одно предложение.
  2. Структура. Что она умеет. Список действий (меню).
  3. Данные. Что хранит: список, словарь, что-то ещё.
  4. Функции. Какие функции нужны. По одной на каждое действие.
  5. Собираешь всё. Главный цикл с меню. Вызовы функций.
  6. Тестируешь. Играешь сам с собой. Ищешь баги.
  7. Полируешь. Форматирование, пустые строки, приятные сообщения.

Проект 1. Записная книжка контактов

Идея: программа для хранения контактов — имя, телефон, email.

Меню:

  • 1 — добавить контакт;
  • 2 — показать все;
  • 3 — найти по имени;
  • 4 — удалить;
  • 5 — выйти.

Данные: список словарей. Каждый словарь — один контакт.

contacts = [
    {"name": "Аня", "phone": "+7-900-111-22-33", "email": "anya@mail.ru"},
    {"name": "Макс", "phone": "+7-900-444-55-66", "email": "max@mail.ru"}
]

Функции:

  • show_menu() — печатает меню;
  • add_contact() — спрашивает данные, добавляет в список;
  • show_all() — выводит все контакты;
  • find_contact(name) — ищет по имени;
  • delete_contact(name) — удаляет.

Проект 2. Угадай число (улучшенный)

Идея: игра, где компьютер загадывает число, а пользователь угадывает. С уровнями сложности.

Уровни:

  • лёгкий — 1–10, 5 попыток;
  • средний — 1–100, 7 попыток;
  • сложный — 1–1000, 10 попыток.

Дополнительно:

  • после каждой попытки подсказка «больше / меньше»;
  • если попытки кончились — показать загаданное число;
  • счёт очков: за каждую попытку минус одно очко, за угадывание плюс десять;
  • спросить, играть ли ещё.

Проект 3. Менеджер списка дел

Идея: todo-приложение в консоли.

Меню:

  • 1 — добавить задачу;
  • 2 — показать все;
  • 3 — отметить выполненной;
  • 4 — удалить;
  • 5 — показать только активные;
  • 6 — выйти.

Данные: список словарей.

tasks = [
    {"text": "сделать уроки", "done": False},
    {"text": "погулять с собакой", "done": True}
]

Украшение: при показе отмечать выполненные звёздочкой или галочкой, невыполненные — пустым квадратом.

[ ] сделать уроки
[✓] погулять с собакой

Проект 4. Викторина

Идея: игра-вопросы на знания. Можно про что угодно — про фильмы, игры, программирование, историю.

Данные: список словарей — вопрос, варианты, правильный ответ.

questions = [
    {
        "question": "Сколько планет в Солнечной системе?",
        "options": ["7", "8", "9", "10"],
        "answer": 2
    },
    {
        "question": "Какой язык создал Гвидо ван Россум?",
        "options": ["Java", "C++", "Python", "Ruby"],
        "answer": 3
    }
]

Логика:

  • перемешать вопросы (random.shuffle);
  • задавать по одному;
  • спрашивать номер ответа;
  • считать баллы;
  • в конце — результат.

Проект 5. Своя идея

Если ни один из этих не вдохновляет — придумай что-то своё. Главное, чтобы в проекте были:

  • меню или структура;
  • минимум 4 функции;
  • список или словарь для данных;
  • цикл, который работает, пока пользователь не выйдет;
  • условия;
  • обработка неверного ввода.

Полезные приёмы

Главное меню.

while True:
    show_menu()
    choice = input("Что делаем? ")

    if choice == "1":
        add_contact()
    elif choice == "2":
        show_all()
    elif choice == "5":
        print("Пока!")
        break
    else:
        print("Не понимаю такую команду")

Проверка ввода.

try:
    age = int(input("Возраст: "))
except ValueError:
    print("Нужно ввести число")
    continue

Пустая строка для красоты.

print()
print("─" * 30)
print()

Функция с параметром и возвратом.

def find_contact(name):
    for contact in contacts:
        if contact["name"].lower() == name.lower():
            return contact
    return None

Как сдавать проект

Не «работает — и хватит». Проверь:

  • все пункты меню работают;
  • если ввести неправильно — программа не падает;
  • сообщения понятны;
  • код разбит на функции, а не всё в одной куче;
  • есть комментарии к сложным местам;
  • ты сама можешь объяснить, что делает каждая функция.

Главное из темы

  • Проект — это не упражнение, а законченная программа.
  • Сначала идея, потом структура, потом код.
  • Каждое действие — отдельная функция.
  • Данные — списки и словари.
  • Главный цикл с меню — основа интерфейса.
  • Обработка ошибок — часть хорошей программы.
  • Сдавать проект = проверить и объяснить каждую часть.
✦ домашка

Цель: сделать минимум один полноценный проект. Можно больше — если хочется.

Выбери проекты (хотя бы один) и сделай. Каждый — отдельный файл:

  • Вариант 1 — Записная книжка контактов. Файл contacts.py. Меню, добавление, показ, поиск, удаление, выход.
  • Вариант 2 — Угадай число (улучшенный). Файл guess_number.py. Уровни сложности, счёт очков, играть ещё.
  • Вариант 3 — Менеджер списка дел. Файл todo.py. Добавление, показ, отметка выполненных, удаление, фильтр.
  • Вариант 4 — Викторина. Файл quiz.py. 5–10 вопросов, подсчёт баллов, случайный порядок.
  • Вариант 5 — своя идея. Что угодно, но с требованиями выше.

Требования для каждого проекта:

  • минимум 4 функции;
  • список или словарь для данных;
  • цикл с меню, выход по команде;
  • условия (if / elif / else);
  • обработка неверного ввода (try / except или проверка);
  • комментарии к сложным местам;
  • аккуратный вывод — разделители, пустые строки, приятные сообщения.

Порядок работы:

  1. Продумай идею. Напиши одним предложением, что делает программа.
  2. Список действий (меню).
  3. Какие функции нужны. Список имён.
  4. Какие данные хранишь. Список или словарь?
  5. Пиши функции по одной. Каждую проверяй через print.
  6. Собери всё в главном цикле.
  7. Тестируй: поиграй сам с собой.
  8. Полируй: сообщения, разделители, отступы.

Проверка перед сдачей:

  • все команды меню работают;
  • при неверном вводе программа не падает;
  • нет ошибок в терминале;
  • можно объяснить каждую функцию;
  • код с комментариями.

Сохрани код в поле «код». Опиши в конспекте, что получилось, что было сложно, что хотелось бы добавить.

Проект можно делать несколько дней. Не торопись. Это финал — сделай так, чтобы было не стыдно показать.
