Переменные и типы данных

как хранить значения и что с ними делать
главная› Python›03
◈ теория

Пока ты писала print("Привет") — это были разовые команды. А что, если значение нужно использовать несколько раз? Или менять по ходу программы? Для этого придумали переменные.

Что такое переменная

Переменная — это «коробка» с именем, в которую можно положить значение. Положить, потом достать, потом заменить.

name = "Аня"
print(name)

Здесь:

  • name — имя переменной;
  • = — знак присваивания (не «равно», а «положи в коробку»);
  • "Аня" — значение, которое кладём.

Важно: в Python = — это присваивание, а не сравнение. Сравнение — это == (два знака). Мы поговорим об этом в теме про условия.

Как пользоваться

После того как переменная создана, можно использовать её имя везде:

name = "Аня"
age = 17
city = "Москва"

print(name)
print(age)
print(city)

print("Меня зовут", name)
print("Мне", age, "лет")
print("Я живу в", city)

Вывод:

Аня
17
Москва
Меня зовут Аня
Мне 17 лет
Я живу в Москва

Обрати внимание: в последних строках мы передаём переменные в print через запятую. Python сам поставит пробелы между ними.

Значение можно менять

Переменная называется переменной, потому что её значение можно перезаписать:

score = 0
print(score)   # 0

score = 10
print(score)   # 10

score = score + 5
print(score)   # 15

В последней строке: «взять текущее значение score (10), прибавить 5, положить обратно в score». Теперь там 15.

Правила именования

Имя переменной может содержать:

  • буквы (латиница — обязательно для надёжности);
  • цифры (но не в начале);
  • знак подчёркивания _.

Можно: name, user_name, age2, my_score.

Нельзя: 2name (начинается с цифры), my-score (дефис), user name (пробел).

Совет: называй переменные по смыслу. Не a, b, c, а name, age, score. Через месяц ты скажешь себе спасибо.

Регистр важен. Name, name и NAME — три разные переменные. Python чувствителен к регистру.

Типы данных

Значения в Python имеют типы. Четыре основных, которые встретятся сразу:

  • str (string) — строка. Текст в кавычках: "Привет", 'Аня'.
  • int (integer) — целое число: 17, -5, 100.
  • float — дробное число: 3.14, -0.5, 2.0.
  • bool (boolean) — логический тип. Только два значения: True или False.
name = "Аня"        # str
age = 17            # int
height = 1.65       # float
is_student = True   # bool

Как узнать тип

Функция type() показывает тип значения:

print(type("Привет"))    # <class 'str'>
print(type(42))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type(True))        # <class 'bool'>

Преобразование типов

Иногда нужно превратить один тип в другой. Три функции:

int("42")      # строка → число: 42
str(42)        # число → строка: "42"
float("3.14")  # строка → дробное: 3.14

Пример:

age_text = "17"
age = int(age_text)
print(age + 1)   # 18

Если бы не преобразовали, Python бы выдал ошибку: нельзя складывать строку с числом.

Что будет, если перепутать типы

print("5" + "3")   # "53" — склеились как строки
print(5 + 3)       # 8 — сложились как числа

Разница огромная. Кавычки решают всё.

print("5" + 3)   # ошибка!

Python не знает, что делать: строка + число — непонятно. Он остановится и скажет: «нельзя».

f-строки — удобный способ соединять текст и переменные

Вместо того чтобы писать длинные print("Меня зовут", name, "и мне", age, "лет"), можно использовать f-строку:

name = "Аня"
age = 17

print(f"Меня зовут {name}, мне {age} лет")

Буква f перед кавычками говорит: «внутри будут переменные». А {name} и {age} — это места, куда Python подставит значения.

Вывод:

Меня зовут Аня, мне 17 лет

Это самый удобный способ работы с текстом. Дальше ты будешь использовать его постоянно.

Внутри фигурных скобок можно даже считать:

print(f"Через год мне будет {age + 1} лет")

Вывод:

Через год мне будет 18 лет

Главное из темы

  • Переменная — «коробка» с именем, куда кладут значение.
  • = — присваивание. == — сравнение.
  • Значение можно менять: score = score + 5.
  • Имена: буквы, цифры (не в начале), _. Регистр важен.
  • Четыре типа: str, int, float, bool.
  • type() — узнать тип.
  • int(), str(), float() — преобразование.
  • f-строки — удобный способ вставлять переменные в текст.
