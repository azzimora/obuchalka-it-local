Функции

Ты уже пользовалась функциями: print(), input(), len(), int(). Это готовые функции Python. А теперь научимся делать свои.

Зачем нужны функции

Представь, что нужно несколько раз посчитать площадь прямоугольника. Можно каждый раз писать a * b. А можно один раз сделать функцию и вызывать её.

Функции дают три вещи:

  • Не повторяться. Написал один раз — используешь много;
  • Понятность. calculate_area(5, 3) читается лучше, чем формула;
  • Исправлять в одном месте. Если что-то поменять — только в функции, а не в десяти местах.

Как создать функцию

def greet():
    print("Привет, мир!")
  • def — ключевое слово, «определить функцию»;
  • greet — имя функции;
  • () — скобки. Внутри могут быть параметры;
  • : — двоеточие;
  • тело — с отступом.

Пока функция только описана. Чтобы она выполнилась — её надо вызвать:

def greet():
    print("Привет, мир!")

greet()   # вызов
greet()   # ещё раз
greet()   # и ещё

Параметры

Параметры — данные, которые функция принимает.

def greet(name):
    print(f"Привет, {name}!")

greet("Аня")
greet("Макс")
greet("Лена")

Вывод:

Привет, Аня!
Привет, Макс!
Привет, Лена!

Можно несколько параметров:

def introduce(name, age):
    print(f"Меня зовут {name}, мне {age} лет")

introduce("Аня", 17)
introduce("Макс", 18)

return — вернуть значение

Функция может не просто что-то делать, а вернуть результат, который можно использовать дальше.

def add(a, b):
    return a + b

result = add(2, 3)
print(result)   # 5

print(add(10, 20))   # 30

Разница между print и return:

  • print — выводит на экран. Значение не возвращается;
  • return — возвращает значение из функции. Можно использовать дальше.
def bad_add(a, b):
    print(a + b)   # выводит, но не возвращает

def good_add(a, b):
    return a + b   # возвращает

x = bad_add(2, 3)    # выведет 5, но x = None
y = good_add(2, 3)   # x = 5

Запомни: если функция должна дать результат для дальнейшего использования — используй return.

return прерывает функцию

Как только Python встречает return — функция сразу заканчивается.

def check_age(age):
    if age < 0:
        return "некорректный возраст"
    if age < 18:
        return "ребёнок"
    return "взрослый"

print(check_age(-5))   # некорректный возраст
print(check_age(15))   # ребёнок
print(check_age(20))   # взрослый

Значения по умолчанию

Параметр может иметь значение по умолчанию — если его не передали, используется оно.

def greet(name, greeting="Привет"):
    print(f"{greeting}, {name}!")

greet("Аня")               # Привет, Аня!
greet("Аня", "Здравствуй") # Здравствуй, Аня!

Параметры со значениями по умолчанию идут после обычных.

Именованные аргументы

Можно передавать значения по имени — тогда порядок не важен:

def introduce(name, age, city):
    print(f"{name}, {age}, {city}")

introduce(age=17, city="Москва", name="Аня")

Функция без return

Если функция ничего не возвращает — она возвращает None (пустое значение).

def show_message():
    print("Привет")

result = show_message()
print(result)   # None

Область видимости

Переменные, созданные внутри функции, не видны снаружи:

def test():
    x = 10
    print(x)

test()
print(x)   # ошибка — x не существует вне функции

А переменные снаружи — видны внутри:

y = 5

def test():
    print(y)   # видит y

test()

Правило: функция не должна зависеть от переменных снаружи. Всё, что ей нужно — передавай через параметры.

Возврат нескольких значений

Функция может вернуть несколько значений — через кортеж.

def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([3, 1, 4, 1, 5])
print(low, high)   # 1 5

Пример: калькулятор

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "делить на ноль нельзя"
    return a / b

print(add(5, 3))
print(subtract(5, 3))
print(multiply(5, 3))
print(divide(5, 3))
print(divide(5, 0))

Пример: проверка пароля

def is_strong(password):
    if len(password) < 8:
        return False
    if password.isdigit():
        return False
    if password.isalpha():
        return False
    return True

pwd = input("Пароль: ")

if is_strong(pwd):
    print("Хороший пароль")
else:
    print("Слабый пароль")

Обрати внимание на методы строк: isdigit() — только цифры, isalpha() — только буквы.

Правила хорошей функции

  • Одно дело. Функция должна делать что-то одно. Не «посчитать и напечатать и сохранить»;
  • Понятное имя. calculate_area лучше, чем f1;
  • Параметры вместо внешних переменных. Всё нужное — через аргументы;
  • Не больше 20–30 строк. Если больше — разбей на несколько функций;
  • return, если нужно значение. print — только если нужно просто вывести.

Главное из темы

  • def name(): — создать функцию.
  • Функция выполняется только при вызове: name().
  • Параметры — данные в скобках.
  • return — возвращает значение. Прерывает функцию.
  • Без return функция возвращает None.
  • Значения по умолчанию и именованные аргументы — удобные штуки.
  • Внутри функции свои переменные, снаружи их не видно.
  • Хорошая функция делает одно дело и имеет понятное имя.
