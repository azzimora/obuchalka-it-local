Ввод данных от пользователя

функция input и что с ней делать
главная› Python›04
◈ теория

До этого программа только выводила данные. Но настоящая программа должна ещё и получать данные от пользователя — имя, число, ответ на вопрос. Для этого есть функция input().

Что делает input

input() останавливает программу, ждёт, пока пользователь что-то напишет и нажмёт Enter. А потом возвращает то, что он написал.

name = input("Как тебя зовут? ")
print(f"Привет, {name}!")

Как это работает:

  • Python выводит текст "Как тебя зовут? " на экран;
  • ждёт, пока ты что-то введёшь и нажмёшь Enter;
  • то, что ты ввела, кладёт в переменную name;
  • идёт дальше — выводит приветствие.

input всегда возвращает строку

Это важно. Что бы пользователь ни ввёл — число, слово, что угодно — input() вернёт строку (тип str).

age = input("Сколько тебе лет? ")
print(type(age))

Если пользователь введёт 17, тип всё равно будет <class 'str'>. А значит, с этим значением нельзя работать как с числом — нельзя складывать, вычитать, сравнивать.

age = input("Сколько тебе лет? ")
print(age + 1)   # ошибка!

Python скажет: «нельзя сложить строку и число».

Преобразование в число

Чтобы работать с введённым числом как с числом, надо преобразовать тип через int() или float():

age = int(input("Сколько тебе лет? "))
print(f"Через год тебе будет {age + 1}")

Здесь: input() вернул строку, int() превратил её в целое число, и теперь можно считать.

Если число может быть дробным (например, рост, вес, цена) — используй float():

height = float(input("Твой рост в метрах? "))
print(f"Твой рост: {height} м")

Как выглядят типичные программы с input

1. Приветствие.

name = input("Как тебя зовут? ")
city = input("Из какого ты города? ")

print(f"Привет, {name} из города {city}!")

2. Калькулятор.

a = int(input("Введи первое число: "))
b = int(input("Введи второе число: "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} * {b} = {a * b}")

3. Анкета.

name = input("Имя: ")
age = int(input("Возраст: "))
hobby = input("Хобби: ")

print()
print("=== Анкета ===")
print(f"Имя: {name}")
print(f"Возраст: {age}")
print(f"Хобби: {hobby}")

Подсказка внутри input

Текст в скобках input() — это подсказка. Он выводится пользователю, чтобы тот понял, что от него хотят.

name = input("Как тебя зовут? ")

Совет: в конце подсказки оставляй пробел — "...? ". Иначе ввод «прилипнет» к вопросу: Как тебя зовут?Аня.

Что если пользователь ошибётся

Если написать int(input()), а пользователь введёт «привет» вместо числа — программа упадёт с ошибкой ValueError.

age = int(input("Возраст: "))   # вводим "привет"
# ValueError: invalid literal for int() with base 10: 'привет'

Пока это нормально — мы просто предполагаем, что пользователь вводит то, что нужно. В будущем научимся обрабатывать такие ошибки.

Полезные мелочи

  • input() ждёт ввода. Программа стоит на месте, пока не нажмёшь Enter.
  • Enter в конце ввода — не часть строки. То есть "Аня", а не "Аня\n".
  • Если пользователь введёт пробелы в начале и конце — они останутся. Чтобы убрать: input().strip().

Главное из темы

  • input() — функция, которая ждёт ввод и возвращает его.
  • Текст в скобках — подсказка для пользователя.
  • input всегда возвращает строку, даже если ввели число.
  • Для чисел — int(input()) или float(input()).
  • Совет: пробел в конце подсказки.
  • Если ввести не то — программа может упасть с ошибкой.
