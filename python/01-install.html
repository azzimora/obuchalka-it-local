Установка Python и VS Code

подготовить рабочее место перед первой программой
главная› Python›01
◈ теория

Чтобы писать код, нужны две вещи: сам Python (программа, которая выполняет код) и редактор (программа, в которой удобно его писать).

Можно, конечно, писать код в блокноте. Но это неудобно: нет подсветки, нет подсказок, нет нормального запуска. Поэтому поставим VS Code — бесплатный редактор от Microsoft, которым пользуются миллионы программистов.

Почему именно Python

  • Простой синтаксис — код читается почти как английский.
  • Огромное сообщество — на любой вопрос уже есть ответ.
  • Подходит для всего: сайты, боты, анализ данных, AI, автоматизация.
  • Один из самых востребованных языков в мире.

Шаг 1 — установка Python

Идёшь на официальный сайт: python.org → раздел Downloads. Сайт сам предложит версию для твоей системы.

  • Скачай установщик — файл вроде python-3.12.x-amd64.exe.
  • Запусти его. Появится первое окно установки.
  • ВАЖНО: внизу окна есть галочка «Add python.exe to PATH». На новых версиях Python она уже стоит по умолчанию — проверь, что она отмечена. Без неё система не найдёт Python, когда ты попробуешь запустить код из командной строки.
  • Нажми «Install Now» — установка по умолчанию. Всё, ничего менять не надо.
  • Дождись окончания и закрой установщик.
  • Скачай установщик — файл вроде python-3.12.x-macos11.pkg.
  • Открой его — запустится обычная установка macOS.
  • Просто нажимай «Continue» / «Agree» / «Install», пока не закончится.
  • На Mac обычно не нужны дополнительные галочки — Python добавится в систему автоматически.
  • Возможно, система спросит пароль — введи свой пароль от Mac.

Шаг 2 — проверка, что Python установлен

Открой терминал:

  • Windows: нажми Win + R, введи cmd, нажми Enter. Или найди «Командная строка» в меню Пуск.
  • macOS: нажми Cmd + Space, начни писать «Terminal», открой его.

В терминале напиши одну из этих команд и нажми Enter:

python --version

Если не сработало (Windows иногда), попробуй:

python3 --version

Если всё хорошо — увидишь что-то вроде:

Python 3.12.4

Это значит, Python установлен и работает.

Заодно проверь, что работает pip — установщик пакетов. Он понадобится дальше, когда будем ставить дополнительные библиотеки:

pip --version

Или на Mac:

pip3 --version

Должно показать что-то вроде pip 24.0 from ....

Если видишь «команда не найдена» или «не является внутренней командой»: скорее всего, на Windows забыта галочка «Add to PATH». Тогда переустанови Python, поставив её. На Mac — попробуй команду python3 вместо python.

Шаг 3 — установка VS Code

Открой code.visualstudio.com и нажми большую кнопку скачивания. Сайт сам определит систему.

  • Скачай VSCodeUserSetup-x64-…exe, запусти.
  • Прими лицензию, дальше просто «Далее».
  • На шаге «Дополнительные задачи» рекомендую оставить галочки по умолчанию. Особенно полезно:
    • «Add to PATH» — чтобы запускать VS Code из терминала командой code;
    • «Open with Code» в контекстном меню — можно будет правой кнопкой по папке открывать её в VS Code.
  • Установи и запусти.
  • Скачай Visual Studio Code.app.zip.
  • Распакуй — появится значок VS Code.
  • Перетащи его в папку Applications (Программы).
  • Открой из Launchpad.
  • VS Code может спросить про доступ к папкам — разреши, если хочешь открывать папки прямо из него.

Шаг 4 — русский язык в VS Code

По умолчанию VS Code на английском. Можно поставить русский:

  • Слева на панели нажми иконку Extensions (четыре квадратика).
  • В поиске набери Russian.
  • Установи расширение Russian Language Pack от Microsoft.
  • VS Code предложит перезапуститься — согласись. Интерфейс станет на русском.

Шаг 5 — расширение Python в VS Code

Это обязательно. Без него VS Code не будет понимать Python-файлы, не будет подсветки, подсказок и кнопки «запустить».

  • Открой Extensions (четыре квадратика слева).
  • В поиске набери Python.
  • Установи расширение Python от Microsoft — оно самое первое, с миллионами загрузок.
  • Обычно оно подхватывается сразу, но иногда VS Code просит перезагрузку — тогда просто перезапусти его.

Шаг 6 — первая папка для проектов

Создай где-нибудь на диске папку, где будут жить твои Python-проекты. Например:

  • Windows: C:\Users\ТвоёИмя\PythonProjects\
  • macOS: /Users/ТвоёИмя/PythonProjects/

Внутри неё потом будешь создавать файлы с расширением .py — это файлы Python.

Открой эту папку в VS Code: Файл → Открыть папку и выбери её. С этого момента VS Code «работает» внутри этой папки.

Шаг 7 — первая программа

В папке создай файл hello.py. Внутри напиши одну строку:

print("Привет, мир!")

Что здесь что:

  • print — это функция. Она выводит то, что ей передали, на экран.
  • ( и ) — скобки. Внутри — то, что нужно вывести.
  • "Привет, мир!" — строка в кавычках. Кавычки нужны, чтобы Python понял: это текст, а не код.

Как запустить:

  • Способ 1 (кнопка в VS Code): в правом верхнем углу нажми значок «▶» — запустить. Внизу откроется терминал и покажет результат.
  • Способ 2 (терминал вручную): открой терминал в VS Code — меню «Терминал → Новый терминал» (или Ctrl + `, если работает). Напиши: 
    python hello.py
    (на Mac — python3 hello.py).

Если внизу появилось «Привет, мир!» — всё работает. Ты только что запустил первую программу на Python.

Если что-то не работает

  • «python не является внутренней или внешней командой» — забыта галочка «Add to PATH» при установке Python. Переустанови, поставив галочку.
  • Кнопка «▶» не появляется — не установлено расширение Python для VS Code. Поставь его (Шаг 5).
  • Ошибка «SyntaxError» — опечатка в коде. Проверь кавычки и скобки.
  • Терминал не открывается — в VS Code меню «Терминал → Новый терминал».

Главное из темы

  • Python — это программа, которая выполняет код; VS Code — редактор, в котором удобно писать.
  • При установке Python на Windows — обязательно галочка «Add python.exe to PATH».
  • Проверка в терминале: python --version или python3 --version. И заодно pip --version.
  • В VS Code нужно расширение Python от Microsoft.
  • Первая программа — файл .py с командой print().
  • Запуск: кнопкой «▶» или командой в терминале.
✦ домашка

Цель: настроить рабочее место и запустить первую программу.

  • Установить Python с официального сайта. Проверить галочку «Add python.exe to PATH» (на Windows).
  • Проверить установку в терминале: python --version или python3 --version. Записать, что показал терминал.
  • Проверить, что работает pip --version. Тоже записать.
  • Установить VS Code.
  • Установить расширение Python от Microsoft (и по желанию — Russian Language Pack).
  • Создать папку для проектов (например, PythonProjects).
  • Внутри папки создать файл hello.py и написать: 
    print("Привет, мир!")
  • Запустить программу — кнопкой «▶» или командой в терминале.
  • Убедиться, что внизу появилось «Привет, мир!». Записать результат в поле «что получилось».
  • Дополнительно: изменить текст внутри кавычек на что-то своё и снова запустить. Убедиться, что вывод изменился.
  • Ещё одно: добавить вторую и третью строку print. Например: 
    print("Привет, мир!")
print("Меня зовут ...")
print("Я учу Python")
    Запустить. Убедиться, что вывелись все три строки.
  • Если что-то не получилось — записать, что именно (ошибка, что не открывается, что не понятно). Это поможет разобраться.
