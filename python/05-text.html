Работа с текстом

методы строк, срезы, склейка
главная› Python›05
◈ теория

Строки в Python — не просто «текст». С ними можно многое делать: считать длину, менять регистр, обрезать, искать, заменять. Это одна из самых частых вещей в программировании.

Длина строки: len()

Функция len() возвращает количество символов в строке.

text = "Привет"
print(len(text))   # 6

Считаются все символы, включая пробелы и знаки:

print(len("Привет, мир!"))   # 12

Индексы: доступ к символам

У каждого символа в строке есть номер — индекс. Нумерация начинается с нуля.

text = "Python"
print(text[0])   # P
print(text[1])   # y
print(text[5])   # n

Можно считать с конца через минус:

print(text[-1])   # n — последний
print(text[-2])   # o — предпоследний

Важно: строки неизменяемы. Нельзя заменить один символ:

text[0] = "J"   # ошибка!

Вместо этого создают новую строку.

Срезы: кусок строки

Срез — это часть строки. Пишется через двоеточие: строка[начало:конец].

text = "Python"
print(text[0:3])   # Pyt — с 0 по 2 (не включая 3!)
print(text[2:5])   # tho
print(text[:3])    # Pyt — с начала до 3
print(text[3:])    # hon — с 3 до конца
print(text[:])     # Python — вся строка

Запомни: конец не включается. [0:3] — это символы 0, 1, 2.

Можно с шагом:

print(text[::2])    # Pto — каждый второй
print(text[::-1])   # nohtyP — строка наоборот!

Строка наоборот — известный трюк. Пригодится.

Методы строк

Метод — это «функция, привязанная к строке». Вызывается через точку: строка.метод().

  • upper() — все заглавные: "привет".upper() → "ПРИВЕТ";
  • lower() — все строчные: "ПРИВЕТ".lower() → "привет";
  • capitalize() — первая заглавная, остальные строчные;
  • title() — каждое слово с заглавной: "привет мир".title() → "Привет Мир";
  • strip() — убирает пробелы с начала и конца;
  • replace(a, b) — меняет все a на b.
text = "  Привет, мир!  "
print(text.strip())               # "Привет, мир!"
print(text.upper())               # "  ПРИВЕТ, МИР!  "
print("Привет".lower())           # "привет"
print("hello".capitalize())       # "Hello"
print("привет мир".title())       # "Привет Мир"
print("Привет".replace("и", "е")) # "Превет"

Поиск: in и find()

Проверить, есть ли подстрока в строке:

text = "Я учу Python"
print("Python" in text)    # True
print("Java" in text)      # False

Найти позицию:

print(text.find("Python"))   # 5
print(text.find("Java"))     # -1 (не найдено)

Разделение и склейка

split() — разбивает строку на список по пробелам (или по указанному разделителю):

text = "яблоко груша слива"
print(text.split())   # ['яблоко', 'груша', 'слива']

csv = "Аня,17,Москва"
print(csv.split(","))  # ['Аня', '17', 'Москва']

join() — склеивает список в строку:

words = ["я", "учу", "Python"]
print(" ".join(words))    # "я учу Python"
print(", ".join(words))   # "я, учу, Python"

Склейка строк

Три способа соединить строки:

# 1. Через +
print("Привет, " + "мир!")

# 2. Через запятую в print (автоматически пробел)
name = "Аня"
print("Привет,", name)

# 3. Через f-строку (самый удобный)
print(f"Привет, {name}!")

Совет: для сложных случаев — f-строки. Для простой склейки двух строк — +.

Число в строке

Если нужно вставить число в строку — оно сначала должно стать строкой:

age = 17
print("Мне " + age + " лет")   # ошибка!
print("Мне " + str(age) + " лет")   # ок
print(f"Мне {age} лет")   # ок, и красивее

Многострочные строки

Тройные кавычки позволяют писать текст в несколько строк:

text = """Это
строка
в три строки"""

print(text)

Полезные мелочи

  • \n — перенос строки внутри строки: "раз\nдва";
  • \t — табуляция;
  • \" — экранированная кавычка, если нужно вставить её в строку.
print("раз\nдва\nтри")

Вывод:

раз
два
три

Главное из темы

  • len() — длина строки.
  • Индексы: с 0, с конца — с -1.
  • Срезы: [начало:конец], конец не включается.
  • [::-1] — строка наоборот.
  • Методы: upper, lower, strip, replace, split, join.
  • in — проверка вхождения.
  • f-строки — лучший способ собирать текст.
  • Строки неизменяемы: нельзя заменить символ по индексу.
